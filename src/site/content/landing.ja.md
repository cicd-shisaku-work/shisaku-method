# shisaku-method（シサクメソッド）

シサクが、実務と内省の n=1 から立ち上げた自作理論群の公開サイトです。人間の認知・表現・変容・価値、そして AI との関わりを、「正しさ」を配る命令ではなく、前提の層（機構・正の用法・失敗機構）から記述しています。

各概念は、原典（理論の本体）と補足でまとまっています。正本は GitHub のリポジトリで、このサイトはそれを人が読み・たどりやすい形にしたものです。

- はじめての方は [README](/ja/readme.html) から。
- 概念ごとに 1 つのまとまり。原典を読み、必要なら補足へ。
