# 日常で扱える

この節に挙げるのは、著者が日常で扱えると考えている形であって、処方ではない。著者自身、その都度選んで使っている。

**見込みを、二つに分けて見る。** いま考えている見込み（「明日は晴れるかな」）と、気づかないまま当然としている見込み（「今日は晴れている」）。自分が何かを変えたいのに、いくら考えても動かないときは、考えているほうではなく、当然としているほうを探してみる。たとえば、話し合うたびに家族とこじれるなら、何を話すかではなく、「言わなくても分かってくれるはずだ」という、一度も口にしたことのない見込みのほうを。

**人に働きかけるなら、相手が当然としているところへ届く形を選び、その働きかけを隠さない。** たとえば、恋人に、もう少し早く寝てほしいとする。「体に悪いよ」と何度言っても、変わらない。自分では、言い方が弱いのだと思っていた。ある晩、「明日の朝、一緒にゆっくり朝ごはんを食べたいから、今日は早く寝てほしい」と、頼む理由をそのまま言う。恋人は少し笑って、「体のこと言われると、怒られてる気がしてたんだよね」と言う。「体に悪い」は、心配でなく、責められることとして届いていた。伝えるなら、責めではなく、一緒にいたい理由のほうだった。

**分かったことと、変わったことを、別のこととして扱う。** たとえば、昔けんか別れした友人のことを、もう気にしていないと思えるようになったとする。人にも「もう何とも思ってない」と話していた。ある日、駅でその友人を見かけた瞬間、体が勝手に向きを変えていた。気にしていないのは、頭の中の言葉のほうだけだった。それからは、言葉で分かったと思えたときほど、実際に、その言葉が示す人や場面と向き合ったとき、自分の中に何が起きるかを見るようにしている——ざわつくのか、何も起きないのか。

**自分の見込みを、世界の写しでなく、自分の経験が組み上げたものとして扱う。** たとえば、恋人のお母さんを、冷たい人だと思っていたとする。電話で挨拶しても、返事がそっけない。自分では、そういう人なのだと思っていた。ある日、恋人が言う。「うちの母さん、電話だと耳が遠くて、半分も聞こえてないんだよ」。冷たい人、は、お母さんの本当の姿ではなかった。何度かの電話から、自分が創り上げた姿だった。それからは、人を「こういう人だ」と思ったときほど、それをどの場面から創り上げたのかを思い出すようにしている——自分が創り上げた姿なら、自分で描き直せる。
