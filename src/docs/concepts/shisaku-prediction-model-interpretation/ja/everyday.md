# 日常で扱える

この節に挙げるのは、著者が日常で扱えると考えている形であって、処方ではない。著者自身、その都度選んで使っている。

**見込みを、二つに分けて見る。** いま考えている見込み（「明日は晴れるかな」）と、気づかないまま当然としている見込み（「今日は晴れている」）。変えたいものが動かないとき、動かすべきは、たいてい後者である。

**人に働きかけるなら、相手が当然としているところへ届く形を選び、その働きかけを隠さない。** 強制の効かない場面では、論点で勝つより、相手が検討の手前で受け入れているものに届くほうが効く。そして、見えないまま働きかけることは、相手が抵抗する機会を奪う（前提優位理論「影：前提は、誤っていても抵抗されない」の節）。

**分かったことと、変わったことを、別のこととして扱う。** 言葉で納得しても、それだけで自分が変わったとは限らない。変わるのは、感じられて、自分の見込みと突き合わされたときである。

**自分の見込みを、世界の写しでなく、自分の経験が組み上げたものとして扱う。** 写しなら正すしかないが、組み上げたものなら、組み替えられる。
