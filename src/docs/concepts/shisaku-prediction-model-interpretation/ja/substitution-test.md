# 置換の検査

本書の読みを既存の学説・概念に置き換えて、何がそのまま成り立ち、何が置き換えた先に無いかを書く。どこが一致し、どこを著者が導出したかは、著者の見立てである。置き換えた先の学説は、本書と同じことを、多くの場合もっと厳密に説明している。確かめたい読み手は、そちらを読めばよい。**本書が差し出すのは、説明の新しさではない。それを日常に落とし、自分の手で扱える形にすることである。**

**予測処理・予測符号化に置き換える。** 「期待を先に出す側がある」は、そのまま成立する。置き換えた先に無いのは、実体と状態を分けることである。予測処理は生成モデルを実体として記述するが、それが**検討されずに働いているのか、検討の対象になっているのか**を分けない。

**自由エネルギー原理・能動的推論に置き換える。** この枠組みは行動も射程に含む（Friston 2010）。だから「知覚の理論だから介入を扱えない」とは言えない。置き換えた先に無いのは、**主語の区別**である。能動的推論が言う行為は、その系が**自分の**予測誤差を下げるために動くことであり、本書と前提優位が扱うのは、**別の系の前提へ外から働きかける**ときの効率の非対称である。加えて、強制力が働かない場面に土俵を限る、という画定が能動的推論には無い。

**暗黙知に置き換える。** 「語れる以上のことを知っている」（Polanyi 1966）。言語化が100パーセントでないことは、そのまま成立する。置き換えた先に無いのは、向きである。暗黙知は「語れない知」を言うが、その知が前提として働いているあいだ検討されない、とは言わない。残るのは、**言葉にすることと、予測モデルが変容することが、別に進む**——という接続のほうである。

**良い調整器の定理に置き換える。** 「あらゆる良い調整器は、その系のモデルでなければならない」（Conant & Ashby 1970）。予測モデルが系一般に及ぶという射程の主張には、ここに先例がある。置き換えた先に無いのは、やはり実体と状態の区別と、言語化の不完全性である。

**予測処理の階層モデルに置き換える。** 「上位の層が下位へ予測を出し、下位から残差が上がる」「予測が外れたときにモデルが更新され、当たっているあいだは変わらない」（Rao & Ballard 1999・Clark 2013）は、そのまま成立する。予測モデルが無数にあり粒度の違うものが重なる、という読みにも、変わるのは照合を経たときだけ、という読みも、そのまま成り立つ。置き換えた先に無いのは、**言葉の位置**である。予測処理の階層モデルは入力の種類で経路を分けない。本書は、考えて出た言葉が接触として同じ入口から入る、と読んだうえで、論じる経路と変容の経路が別に進む、と言う。**経路は二本で、つながり目は接触だけ**——この形は予測処理の階層モデルに無い。

**記憶の再固定化に置き換える。** 「固定された記憶も、想起されると一時的に不安定になり、書き換わりうる」（Nader ほか 2000）は、そのまま成立する。本系列の共鳴の構造理論が既にこれを引いている。「変わるのは接触と照合を経たときだけ」も、そのまま成り立つ——記憶の再固定化が言う想起は手がかりによる再活性化で、系列の言い方では接触である（〔シサク・クオリア解釈〕）。置き換えた先に無いのは、**想起を二つに分けること**である。記憶の再固定化は、想起されれば不安定になる、と一本で書く。本書は、想起のうち、言葉で論じることと、感じられて接触になることを分ける——A さんのことを言葉で考えるだけでは変わらず、会って、あるいは思い描いて身体がざわついたときに変わりうる。

**ソマティック・マーカー仮説に置き換える。** 「過去の結末と結びついた身体の変化が、次の判断を先に導く」（Damasio 1994）は、そのまま成立する。身体の側にある、という点も、そのまま成り立つ。思い描いただけで身体が応じる、という点は、系列が思い描いた像を接触に数えること（〔シサク・クオリア解釈〕）と同じ向きである。置き換えた先に無いのは、**マーカーを次の期待の側に置くこと**である。ソマティック・マーカー仮説は身体の変化を、過去の結末と結びついた印として読む。本書は、記憶を予測モデルの側——次の期待を出す側——に置き、身体の変化を、その期待と接触の照合に伴って現れるもの（〔シサク・クオリア解釈〕）として読む。

**置き換えても残るもの——日常で扱える四つ。**

**見込みを、二つに分けて見る。** いま考えている見込みと、気づかないまま当然としている見込み。変えたいものが動かないとき、動かすべきは、たいてい後者である。

**人に働きかけるなら、相手が当然としているところへ届く形を選び、その働きかけを隠さない。** 強制の効かない場面では、論点で勝つより、相手が検討の手前で受け入れているものに届くほうが効く。そして、見えないまま働きかけることは、相手が抵抗する機会を奪う（前提優位理論「影：前提は、誤っていても抵抗されない」の節）。

**分かったことと、変わったことを、別のこととして扱う。** 言葉で納得しても、それだけで自分が変わったとは限らない。変わるのは、感じられて、自分の見込みと突き合わされたときである。

**自分の見込みを、世界の写しでなく、自分の経験が組み上げたものとして扱う。** 写しなら正すしかないが、組み上げたものなら、組み替えられる。
