# 置換の検査

本書の読みを既存の概念に置き換えて、何がそのまま成立し、何が崩れるかを置く。**成立する部分に、本書の核は無い。**

**予測処理・予測符号化に置き換える。** 「期待を先に出す側がある」は、そのまま成立する。ここに核は無い。崩れるのは、実体と状態を分けることである。予測処理は生成モデルを実体として記述するが、それが**検討されずに働いているのか、検討の対象になっているのか**を分けない。

**自由エネルギー原理・能動的推論に置き換える。** この枠組みは行動も射程に含む（Friston 2010）。だから「知覚の理論だから介入を扱えない」とは言えない。崩れるのは**主語**である。能動的推論が言う行為は、その系が**自分の**予測誤差を下げるために動くことであり、本書と前提優位が扱うのは、**別の系の前提へ外から働きかける**ときの効率の非対称である。加えて、強制力が働かない場面に土俵を限る、という画定が向こうには無い。

**暗黙知に置き換える。** 「語れる以上のことを知っている」（Polanyi 1966）。言語化が100パーセントでないことは、そのまま成立する。ここにも核は無い。崩れるのは向きである。暗黙知は「語れない知」を言うが、その知が前提として働いているあいだ検討されない、とは言わない。残るのは、**言葉にすることと、予測モデルが変容することが、別に進む**——という接続のほうである。

**良い調整器の定理に置き換える。** 「あらゆる良い調整器は、その系のモデルでなければならない」（Conant & Ashby 1970）。予測モデルが系一般に及ぶという射程の主張には、ここに先例がある。崩れるのは、やはり実体と状態の区別と、言語化の不完全性である。

**予測処理の階層モデルに置き換える。** 「上位の層が下位へ予測を出し、下位から残差が上がる」「予測が外れたときにモデルが更新され、当たっているあいだは変わらない」（Rao & Ballard 1999・Clark 2013）は、そのまま成立する。予測モデルが無数にあり粒度の違うものが重なる、という読みにも、変わるのは照合を経たときだけ、という読みにも、ここに核は無い。崩れるのは、**言葉の位置**である。向こうは入力の種類で経路を分けない。本書は、考えて出た言葉が接触として同じ入口から入る、と読んだうえで、論じる経路と変容の経路が別に進む、と言う。**経路は二本で、つながり目は接触だけ**——この形は向こうに無い。

**記憶の再固定化に置き換える。** 「固定された記憶も、想起されると一時的に不安定になり、書き換わりうる」（Nader ほか 2000）は、そのまま成立する。本系列の共鳴の構造理論が既にこれを引いている。「変わるのは接触と照合を経たときだけ」に、核は無い——向こうの想起は手がかりによる再活性化で、本書の言い方では接触である。崩れるのは、**想起を一本で書くこと**である。向こうは、想起されれば不安定になる、と一本で書く。本書は、想起のうち、言葉で論じることと、感じられて接触になることを分ける——A さんのことを言葉で考えるだけでは変わらず、会って、あるいは思い描いて身体がざわついたときに変わりうる。

**ソマティック・マーカー仮説に置き換える。** 「過去の結末と結びついた身体の変化が、次の判断を先に導く」（Damasio 1994）は、そのまま成立する。身体の側にある、という点にも核は無い。思い描いただけで身体が応じる、という点は、本書が思い描いた像を接触に数えることと同じ向きである。崩れるのは、**マーカーが過去の側に置かれている**ことである。向こうは身体の変化を、過去の結末と結びついた印として読む。本書は、記憶を予測モデルの側——次の期待を出す側——に置き、身体の変化を、その期待と接触の照合に伴って現れるもの（〔シサク・クオリア解釈〕）として読む。

**置き換えても残るもの（四つ）。** 実体と状態を分けること。介入の主語の非対称と、土俵の画定。言葉にする経路と、予測モデルが変容する経路が別に進むこと。そして、身体の内にあるのは写しではなく、その人の内で予測されたモデルであること——言葉の形で残るものも、次元が低いだけで同じ側にある。

構成要素はいずれも既知である。新しいのは、それらの関係構造への圧縮であって、要素そのものではない。
