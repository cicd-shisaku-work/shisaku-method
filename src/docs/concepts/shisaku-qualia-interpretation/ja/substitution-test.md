# 置換の検査

本書の読みを既存の学説・概念に置き換えて、何がそのまま成り立ち、何が置き換えた先に無いかを書く。どこが一致し、どこを著者が導出したかは、著者の見立てである。置き換えた先の学説は、本書と同じことを、多くの場合もっと厳密に説明している。確かめたい読み手は、そちらを読めばよい。**本書が差し出すのは、説明の新しさではない。それを日常に落とし、自分の手で扱える形にすることである。**

**フェルトセンスに置き換える。** 「言葉になる前の、身体の感じがある」「多くは微妙で曖昧である」は、そのまま成立する。置き換えた先に無いのは二点である。ひとつ、**期待との食い違いとして読むこと**。フェルトセンスは状況の全体についての身体の感じであって、期待との食い違いとして定義されていない。ふたつ、象徴化がフェルトセンスを動かす（フェルトシフト）という点での、**何が動いたかの読み**。言葉が身体に効くこと自体は、〔シサク・予測モデル解釈〕も言う——言葉は接触として戻り、照合で食い違えば予測モデルを変えうる。フェルトシフトでは、同じ感じが言葉によって動く。本書の読みでは、言葉が接触として戻って照合され、そこに新しい信号が現れている——動いたのは元の感じではない。

**ソマティック・マーカー仮説に置き換える。** 「身体が先に信号を出し、判断を導く」（Damasio 1994）は、そのまま成立する。置き換えた先に無いのは、**種類で分けない読み**である。ソマティック・マーカー仮説では、マーカーが種類で分かれている（不安に動悸、嫌悪に吐き気）。本書の読みでは、**種類に見えているのは、減って出たあとの姿**である。減る前の側を、本書は種類で分けない。

**コア・アフェクトに置き換える。** 「感じられる原始的な土台がある」は、そのまま成立する。置き換えた先に無いのは、**次元の読み**である。コア・アフェクトは快‐不快と覚醒の二次元で表す。本書は、**二次元で表した時点で減っている**と読む。二次元は記述の便宜であって、元の姿ではない。

**予測誤差・精度重み付けに置き換える。** 「期待と接触の差がある」「その差に大きさがある」は、そのまま成立する。置き換えた先に無いのは二点である。ひとつ、**予測誤差という記述量そのものを、本書は身体感覚と同一視しない**——記述量として書き取られた時点で、本書の言う減少が既に起きている。ふたつ、**予測誤差は差を扱う枠組みであり、一致は誤差ゼロとして扱われる**——一致の側に何が現れるかを言わない。ただし**それを言う枠組みは別にある**（処理流暢性の項）。

**処理流暢性・正しさの感覚に置き換える。** 処理が容易であること——入力が既に持っているものと合うこと——が**感じられる**、という主張は既にある。「客観的な流暢性は、処理の容易さという意識経験（主観的流暢性）を生みうる」「流暢性が意識に上るとき、それは意識の周辺で、ぼんやりした『縁』の経験として感じられる」「高い流暢性は、より肯定的な評価と確かに結びつく」（Reber・Wurtz・Zimmermann 2002）。身体の側の相関も測られている（大頬骨筋の活動・Winkielman・Cacioppo 2001）。推論の側では、流暢に出てきた答えに**正しさの感覚**（feeling of rightness）が伴うとされる（Thompson ほか 2011）。**「一致も現れる」は、ここで既に言われている。**

置き換えた先に無いのは二点である。ひとつ、**多次元であること**。処理流暢性の研究が言うのは低次元のもの——「ぼんやりした容易さの感じ」「肯定的な方向」——である。本書が言う照合結果は多次元で、種類に分かれていない。ふたつ、**減る前の側**。処理流暢性の研究は、それを判断の手がかり（cue）として位置づける——判断に使われる入力である。本書の読みでは、その「ぼんやりした快」は**既に減ったあとの姿**であって、減る前の側ではない。**つまり処理流暢性の研究が記述しているのは、本書の言うクオリア表出のほうである。**

**内受容的推論に置き換える。** 身体の状態を予測し、身体が応じ、それがまた感じられる——この循環は、内受容的推論が既に持っている（Seth 2013）。**本書の「出たものは、また接触になりうる」の節は、ここでほぼそのまま成り立つ。** 置き換えた先に無いのは、**出ていく側と入ってくる側で、次元の向きが揃っていない**という一点である——出るときは減り、出たものが接触として照合されると、そこにまた多くの次元を持つ信号が現れる。

**置き換えた先に無く、著者が導出したもの。**

**出ることは、次元が減ることである。** 言語について部分性を言う説はある（フェルトセンス・暗黙知）。身体反応を種類で記述する説もある（ソマティック・マーカー）。だが、**言語も反射も同じ一つの機構で読み、減る前の側を一つだけ残す**——この形は、**本書が置き換えを試した先のどれにも無かった。**

置き換えても残るのは、「日常で扱える」の節に挙げたものである。
