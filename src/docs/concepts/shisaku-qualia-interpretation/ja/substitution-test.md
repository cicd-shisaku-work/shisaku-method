# 置換の検査

本書の読みを既存の概念に置き換えて、何がそのまま成立し、何が崩れるかを置く。**成立する部分に、本書の核は無い。**

**フェルトセンスに置き換える。** 「言葉になる前の、身体の感じがある」「多くは微妙で曖昧である」は、そのまま成立する。ここに核は無い。崩れるのは二点。向こうは**状況の全体についての身体の感じ**であって、**期待との食い違いとして定義されていない**。そして、象徴化がフェルトセンスを動かす（フェルトシフト）という点は、〔シサク・予測モデル解釈〕が「言葉にする経路と、予測モデルが変容する経路は別に進む」と言うのと、**向きが揃っていない**。

**ソマティック・マーカー仮説に置き換える。** 「身体が先に信号を出し、判断を導く」は、そのまま成立する。ここにも核は無い。崩れるのは、**マーカーが種類で分かれている**ことである（不安に動悸、嫌悪に吐き気）。本書の読みでは、**種類に見えているのは、減って出たあとの姿**である。減る前の側を、本書は種類で分けない。

**コア・アフェクトに置き換える。** 「感じられる原始的な土台がある」は成立する。崩れるのは**次元**である。向こうは快‐不快と覚醒の二次元で表す。本書は、**二次元で表した時点で減っている**と読む。二次元は記述の便宜であって、元の姿ではない。

**予測誤差・精度重み付けに置き換える。** 「期待と接触の差がある」「その差に大きさがある」は、そのまま成立する。ここに核は無い。崩れるのは二点。ひとつ、**予測誤差という記述量そのものを、本書は身体感覚と同一視しない**——記述量として書き取られた時点で、本書の言う減少が既に起きている。ふたつ、**向こうは差を扱う枠組みであり、一致は誤差ゼロとして扱われる**——一致の側に何が現れるかを言わない。ただし**それを言う枠組みは別にある**（次項）。

**処理流暢性・正しさの感覚に置き換える。** 処理が容易であること——入力が既に持っているものと合うこと——が**感じられる**、という主張は既にある。「客観的な流暢性は、処理の容易さという意識経験（主観的流暢性）を生みうる」「流暢性が意識に上るとき、それは意識の周辺で、ぼんやりした『縁』の経験として感じられる」「高い流暢性は、より肯定的な評価と確かに結びつく」（Reber・Wurtz・Zimmermann 2002）。身体の側の相関も測られている（大頬骨筋の活動）。推論の側では、流暢に出てきた答えに**正しさの感覚**（feeling of rightness）が伴うとされる。**だから「一致も現れる」に、本書の核は無い。**

崩れるのは二点。ひとつ、**向こうが言うのは低次元のもの**である——「ぼんやりした容易さの感じ」「肯定的な方向」。本書が言う照合結果は多次元で、種類に分かれていない。ふたつ、**向こうはそれを判断の手がかり（cue）として位置づける**——判断に使われる入力である。本書の読みでは、その「ぼんやりした快」は**既に減ったあとの姿**であって、減る前の側ではない。**つまり向こうが記述しているのは、本書の言うクオリア表出のほうである。**

**内受容的推論に置き換える。** 身体の状態を予測し、身体が応じ、それがまた感じられる——この循環は、向こうが既に持っている（Seth 2013）。**本書の再帰の節は、ここで大きく成立してしまう。ここに核は無い。** 残るとすれば、**出ていく側と入ってくる側で、次元の向きが揃っていない**という一点だけである——出るときは減り、出たものが接触として照合されると、そこにまた多くの次元を持つ信号が現れる。

**置き換えても残るもの。**

**出ることは、次元が減ることである。** 言語について部分性を言う説はある（フェルトセンス・暗黙知）。身体反応を種類で記述する説もある（ソマティック・マーカー）。だが、**言語も反射も同じ一つの機構で読み、減る前の側を一つだけ残す**——この形は、**本書が置き換えを試した先のどれにも無かった。**

構成要素はいずれも既知である。新しいのは、それらの関係構造への圧縮であって、要素そのものではない。
