# 同じ一つから、違う二つが出る

演奏を聴いている。次にどう進むかを、聴き手は先に持っている。**そこを外される。**

背中が粟立つ感じがある。そのとき身体に現れているものは、一つの量ではない。**これが、まだ何も出ていない状態のクオリアである。**

ここから二つのものが出る。一つは**鳥肌**。立つか立たないかの一本になって出た。もう一つは、訓練を受けた聴き手なら「**半音下がった**」という語。こちらは五文字になって出た。

**どちらも、同じ一つのものから出ている。そして、どちらも元より少ない。** 鳥肌が立ったことを言えても、そのとき身体に現れていたものが全部、鳥肌に入っているわけではない。「半音下がった」と言えても、粟立ちはその語に入っていない。

**それぞれが、違う方向に減った。**

〔シサク・予測モデル解釈〕のキーボードの例は、演奏の例の裏側にあたる。使い込んでキーが削れ、指が一瞬迷い、「すり減ってきた」と分かる——**あそこで言葉になったのは、指が受け取っていたもののごく一部だった。** 本書の言い方では、指の側に現れていたものがクオリアで、「すり減ってきた」が、減って出たクオリア表出である。

**同じ例の、迷う前のほうが、一致の側である。** 打っているあいだ、指は突起を手がかりに元の位置へ戻り続けている——使っているが、検討していない。そのとき照合は一致の側にあり、表出は**指が動き続けること**である。**一致は、何も起きないことではない。** ここでは、そのまま進むことが表出になっている。
