# クオリアは、予測モデルと接触の照合に伴って身体に現れる信号である

予測モデルは、**接触**——入ってきたもの——より先に期待を出している。そこへ接触が来て、突き合わされる。**その照合に伴って身体に現れるものを、私はクオリアと呼ぶ。**

**ここでいう信号は、別の何かを伝える媒体ではない。身体に現れた、その状態そのものを指す。** 胸のあたりが詰まる感じ、背中が粟立つ感じ——**それが信号である。** 身体感覚を表す何かではなく、身体感覚そのものである。

**一致しても現れる。** 一致は「何も起きない」ではない——**そのまま進める**、という結果が現れる。**ただし、現れていることと、気づかれることは別である。** 一致の側は、多くのばあい気づかれないまま働いている。

**照合結果は、一致と不一致の二値ではない。** そのあいだを連続して変化し、強度を持つ。不一致の側には、ビビッと来るもの、強い疑念、強い違和感、そして**軽いもやもや**がある。どこかで種類が切り替わるのではなく、一致の側から不一致の側へ、連続している。

**照合を経ていないものは、クオリアではない。** 予測モデルと接触の照合に伴って身体に現れる信号である、という読みの裏側である。
