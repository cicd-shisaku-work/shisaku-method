# 出たものは、また接触になりうる

減って出たものは、そこで終わらない。**それ自身が、次の接触になる。**

胸が騒ぐ——その信号から、心拍の速まりや呼吸の浅さが出る。**出たものが感じられた時点で、それが新しい接触である。** 予測モデルはそれを受けて、次の期待を出す。その期待と、いま起きていることが、また照合される。また身体感覚が現れる。

**予測モデルは、ここで異常なことをしていない。** 身体の状態を手がかりにして次を予測する、いつもの仕事をしている。**だから止まりにくい。** 系の外から何かが壊れているのではなく、系が正しく働いたまま、自分の出力を入力として回り続ける。

**一つだけ、向きが揃っていない。** 出ていくときは次元が減る。ところが、それが接触になって照合されると、**そこにまた、多くの次元を持つ信号が現れる。**

**減ったものが膨らんで戻るのではない。** 戻ってきたものは、新しい接触として照合され、**その照合が新しく信号を生んでいる**。同じものが帰ってきているのではなく、出ていく側と入ってくる側で、次元の向きが揃っていない。
