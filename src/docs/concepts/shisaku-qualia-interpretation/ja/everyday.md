# 日常で扱える

この節に挙げるのは、著者が日常で扱えると考えている形であって、処方ではない。著者自身、その都度選んで使っている。

**違和感を、言葉にする前に、身体のどこに出ているかで見る。** 胸が詰まるのか、背中が粟立つのか。言葉にする前の身体のほうが、多くを抱えている。

**言葉にしたものを、感じたものの全部と取り違えない。** 「不安」と言えても、それは自分が扱いやすいように貼ったラベルで、箱の中身——元の感じ——は、それより多い。言葉にしたあとで、まだ残っているものがあるかを見る。

**軽いもやもやを、捨てない。** 軽いもやもやも、強い違和感と同じ連続の上にある。「あれ？」と感じたら、そこには、当然だと思っていたのに外れたものがある。

**身体の反応が次の反応を呼んで止まらないとき、自分のどこかが壊れていると決めつけない。** 予測モデルは正しく働いたまま、自分の出したものを受けて回っている。
