# 日常で扱える

この節に挙げるのは、著者が日常で扱えると考えている形であって、処方ではない。著者自身、その都度選んで使っている。

**違和感を、言葉にする前に、身体のどこに出ているかで見る。** たとえば、週末の予定を一人で決めてしまったあとで、恋人に「別にいいよ」と言われたとする。言葉の上では、了解である。それでも、胸のあたりが詰まる。責められたときの、背中が冷える感じとは違う——何かを飲み込ませてしまったときの詰まり方だった。「本当は、よくなかったんじゃない？」と聞くと、恋人は少し黙ってから、「ほんとは、一緒に決めたかった」と言う。言葉にする前の胸のほうが、先に知っていた。

**言葉にしたものを、感じたものの全部と取り違えない。** 「不安」と言えても、それは自分が扱いやすいように貼ったラベルで、箱の中身——元の感じ——は、それより多い。たとえば、恋人の遠くへの転勤が決まったとする。友人に「どう？」と聞かれ、「ちょっと不安で」と答える。言葉にできて、少し楽になった。その夜、恋人が、二人で使ってきたマグカップを手に取り、しばらく眺めてから棚に戻すのを見る。胸のあたりが詰まる。自分が抱えていた、「不安」というラベルが貼られた箱には、この部屋で二人で過ごした朝が、まだ入っていた。それからは、わかりやすい言葉のラベルができたときほど、そのラベルの箱に、まだ何が残っているかを開けてみるようにしている。

**軽いもやもやを、捨てない。** 軽いもやもやも、強い違和感と同じ連続の上にある。たとえば、久しぶりに実家へ帰ったとする。母はいつもどおり笑って迎えてくれる。何も変わっていないと思った。ただ、台所に立つ母の背中を見て、ほんの少し「あれ？」と思う。気のせいだと流しかけて、「最近、疲れてない？」と聞くと、母は少し間を置いて、「実はね、先月から病院に通ってるの」と言う。ふだんどおりだと思っていた母の姿が、少しだけいつもとは違っていた。あの「あれ？」は、それに気づいていたのだ。それからは、ほんの小さな「あれ？」ほど、流さずに、何がいつもとは違うのかを、一度だけ確かめるようにしている。

**身体の反応が次の反応を呼んで止まらないとき、自分のどこかが壊れていると決めつけない。** たとえば、恋人の家族に初めて挨拶に行く日だとする。玄関の前で、心臓が速くなる。速くなっていることに気づくと、もっと速くなる。自分はどこかおかしいのではないかと思い始める。そのとき恋人が、「わたしも、あなたの実家に初めて行ったとき、そうなったよ」と笑う。おかしくなっていたのではなかった。速くなった心臓に体が気づいて、それでまた速くなっていただけだった。それからは、体の反応が止まらなくなったときほど、おかしくなったのではなく、ドキドキが、ドキドキを呼んでいるだけだと見るようにしている。ただ、思い当たる理由もないのに、急な動悸や息苦しさが繰り返し起きるなら、それはパニック発作など、医療が扱うことかもしれない。そのときは、一人で抱えずに、医療機関に相談してほしい。
