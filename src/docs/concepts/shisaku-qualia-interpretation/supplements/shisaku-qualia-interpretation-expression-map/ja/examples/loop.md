# パニック障害におけるループ

出た表出が新しい接触になる、という原典の再帰が、極端な形で現れる場面がある。身体の感覚と、それを危険と読むことが互いを強め合う悪循環は、パニックの認知モデルが描いている（Clark 1986）。

不快感が現れる。そこから心拍の速まりが出る。**出たものが感じられた時点で、それが新しい接触になる。** 予測モデルはそれを受けて、次の期待を出す——また来る、という期待である。その期待と、いま起きていることが照合される。予期不安が現れる。動悸がさらに速まる。

**予測モデルは、ここで異常なことをしていない。** 身体の状態を手がかりにして次を予測する、いつもの仕事をしている。**だから止まりにくい。**

**本資料は、これを臨床の主張として置かない。** 機構がこう読める、というところまでである。診断も治療も本資料の射程の外にある。
