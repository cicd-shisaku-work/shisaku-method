# 一つの照合状態から、違う形へ

| 接触 | 照合 | 出た形 |
|---|---|---|
| 演奏が、予想と違う進み方をする | 不一致・強 | 鳥肌（反射の形）／「半音下がった」（言葉・訓練のある聴き手のみ） |
| 自分の書いた文を読み返す | 不一致・弱 | 直す手が動く（行為）／「主語がずれている」（理解） |
| 契約書の一文に引っかかる | 不一致・弱 | 読み返す（行為）／「責任の所在が抜けている」（理解） |
| 久しぶりの実家の匂い | 不一致・中 | 懐かしさ（心象）——言葉にならないまま終わることがある |
| 初対面の人に、理由なく警戒する | 不一致・中 | 距離を取る（行為）——言語化されないまま終わることがある |
| F と J に指を置いて打ち続けている | 一致 | 指が動き続ける——そのまま進む |
| 使い込んでキーが削れている | 不一致・弱 | 指が一瞬迷う（反射の形）／「すり減ってきた」（言葉） |

**同じ接触から、複数の形が同時に出ることがある。** そして**形ごとに、落ちるものが違う**。「半音下がった」に粟立ちは入っておらず、鳥肌に和声の位置は入っていない。

**一致の側は、形を持たないのではない。** 指が動き続けることが、その表出である。ただし**現れていることと、気づかれることは別**であり、一致の側は多くのばあい気づかれないまま働いている。
