# 位置づけ

本資料は**地図**である。〔シサク・クオリア解釈〕が「中身と例は補足が担う」と言って本文に置かなかったもの——**表出の形の候補、扱わないものの例、そして接地**——を受ける。

**不変の地図であって、実装のプロファイルではない。** 判別子は一問——**道具や運用の形を変えても起きるか。** 起きるならここに置く。特定の実装・特定の運用の形でしか起きないなら、ここではなくプロファイルに属す。

本資料は原典に従属する。原典が持つのは機構（照合に伴って身体に現れる信号と、そこから出ることが次元を減らすこと）で、**本資料が持つのは、その機構が実際にどんな形をとるかの候補と、候補を篩にかける手続きである。**
