# 接地

**以下は傍証であって、証明ではない。** 原典はクオリアの発生を哲学的な原始項として扱い、機構を主張しない。ここに並べるのは、外の記述と本資料の読みが、どこで重なりどこで離れるかの目印である。

- **脊髄反射。** 熱いものからの引っ込めは、脳を経由する前に脊髄で閉じるとされる。「本資料が扱わないもの」の一件目の目印。
- **音楽の鳥肌（frisson）。** リズム・強弱・和声・旋律が聴き手の明示的または暗黙の**期待を破る**ことが前提条件とされ（Sloboda 1991）、経路は報酬系と交感神経（側坐核・眼窩前頭皮質・島皮質——Blood・Zatorre 2001／Salimpoor ほか 2011）。**脊髄反射ではない。** 「反射の形」の節の目印であり、同時に、照合を経た反射という読みの傍証になる。
- **体温調節。** 寒さによる立毛は視床下部の調節とされる——体温の設定値と、いまの体温との突き合わせである。寒さの鳥肌が、生まれつきの期待との照合を経ている、という読みの目印（「本資料が扱わないもの」の節の鳥肌の段落）。
- **ソマティック・マーカー仮説**（Damasio 1994）。身体の変化が種類で分かれるとされる（不安に動悸、嫌悪に吐き気）。**本資料の読みでは、その種類差は出たあとの側にある。**
- **処理流暢性**（Reber・Wurtz・Zimmermann 2002）。処理が容易であることが、周辺の、ぼんやりした経験として感じられ、肯定的な評価と結びつくとされる。身体の側の相関も測られている（大頬骨筋の活動・Winkielman・Cacioppo 2001）。**一致の側にも形があるという読みの傍証。** ただし処理流暢性の研究が記述しているのは低次元のもので、本資料の読みでは、それは既に減ったあとの姿である。
