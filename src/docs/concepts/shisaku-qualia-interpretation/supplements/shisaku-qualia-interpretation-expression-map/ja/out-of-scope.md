# 本資料が扱わないもの

**照合を経ていないものは、表出ではない。** 減る元を持っていないからである。

- **熱いものに触れて手を引く。** 脊髄で閉じていて、期待との照合を経ていない。

**鳥肌は、見た目では決まらない。** 音楽で立つ鳥肌は、次にどう進むかの期待との照合を経ている。寒さで立つ鳥肌も、体温についての生まれつきの期待との照合を経ている（原典「クオリアは、予測モデルと接触の照合に伴って身体に現れる信号である」の節）。熱いものから手を引く動きは、見た目は同じく素早い身体の反応でも、脊髄で閉じていて照合を経ていない。**同じ素早い反応が、由来で別の側に落ちる。** これが、「照合を経ているか」が見た目ではなく由来を見ている理由である。
