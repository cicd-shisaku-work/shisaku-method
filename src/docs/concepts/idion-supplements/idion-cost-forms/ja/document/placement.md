# 位置づけ（原典／応用の線）

原典は「変容コスト」を、**書き換え要求が立ってから書き換わるまでに本人の内部で要る処理**と定義し、その形態が複数あること・闘いはその一形態であること・形を決める変数（否定する量・慣性）・変容コストと変容量が別の量であること、までを置く（構造の節・公理の節）。原典は形態の一覧を置かない。本資料はその一覧＝**地図**であり、実装非依存で、複数の実装が共有する。

判別子は一問——**その項目は、媒体・受け手・文脈を変えても不変か。** 不変なもの（変容コストという軸の存在・闘いと統合の区別・形を決める変数）は原典にあり、本資料はその下の候補集合である。形態の一覧は候補であって網羅でなく、独立性・閉包性は未証明である。
