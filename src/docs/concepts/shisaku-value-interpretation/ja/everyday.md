# 日常で扱える

この節に挙げるのは、著者が日常で扱えると考えている形であって、処方ではない。著者自身、その都度選んで使っている。

**売れなかったとき、理由を一つにしない。** 山頂でジュースを買わなかった人が、二人いるとする。一人は水筒が満タンで、もう一人は炭酸が苦手だ。満タンの人は、渇けば戻ってくるかもしれない。炭酸が苦手な人は、渇いても戻ってこないかもしれない。買われなかったのが、そのときの渇きのせいなのか、その人がずっと持っている好みのせいなのかを、分けて見る。

**値段の「高い」と、価値の「高い」を、一つのことと思わない。** 値札を見て「高いな」と思うのと、使ってみて「これは、自分には高い価値がある」と思うのとは、同じ「高い」でも、出てきた元が違う。たとえば、恋人の誕生日に、少し無理をして財布を贈ったとする。値札を見たときは、高いと思った。何年かして、恋人がくたびれたその財布を、まだ大事そうに使っているのを見る。「これ、高かったでしょ」と言われて、「うん」とだけ答えた。値札の「高い」は、もう思い出せない。財布のほうの「高い」は、まだ続いていた。値段の高さは、払ったときに一度きりで終わる。価値の高さは、使い手の中に残り続ける。

**差し出したものが立たなかったとき、それだけで、差し出したものが悪かったとは決めない。** たとえば、久しぶりに家族に手料理をふるまったとする。自信のあった煮物に、上の子は二回おかわりをし、下の子はほとんど手を付けない。やっぱり味が足りなかったのかと、自分では思っていた。片づけのとき、下の子が小さな声で言う。「今日、給食で同じようなの食べたんだ」。煮物が悪かったのではなかった。同じ一皿でも、残るものは、食べる人とその日によって変わる。届かなかった理由は、差し出したものの中だけにあるとは限らない。

**評判と、自分に立ったものを、分けて見る。** たとえば、恋人と、行列のできる評判の店に行ったとする。雑誌にも載っていた店だ。食べ終えて、恋人が「おいしかったね」と言う。自分も「うん」と返した。けれど、数日後には、何がおいしかったのか、よく覚えていない。それよりも、一年前、雨宿りに入った古い食堂で、二人で分けた焼きそばのほうを、今でもときどき思い出す。評判は、多くの人が「おいしい」と言ったことの集まりで、自分に何が残るかとは別だった。人の「いい」は、自分の「いい」を代わりに決めてはくれない。
