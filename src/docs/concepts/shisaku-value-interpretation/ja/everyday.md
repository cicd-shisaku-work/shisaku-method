# 日常で扱える

この節に挙げるのは、著者が日常で扱えると考えている形であって、処方ではない。著者自身、その都度選んで使っている。

**売れなかったとき、理由を一つにしない。** 山頂でジュースを買わなかった人が、二人いるとする。一人は水筒が満タンで、もう一人は炭酸が苦手だ。前の人は、渇けば戻ってくるかもしれない。後の人は、渇いても戻ってこないかもしれない。立たなかったのが相手の状態なのか、相手の内に留まるものなのかを、分けて見る。

**値段の「高い」と、価値の「高い」を、一つのことと思わない。** 値札を見て「高い」と感じるのは、値段という数に触れて出た語である。使ってみて「これは高い価値がある」と感じるのは、物に触れて自分の側に立ったものから出た語である。同じ「高い」でも、出てきた元が違う。

**差し出したものが立たなかったとき、それだけで、差し出したものが悪かったとは決めない。** 同じ文章を差し出しても、ある人には刺さり、ある人には何も残らないことがある。価値は受け手の側に立つので、立ち方がばらつくのは欠陥ではない。

**評判と、自分に立ったものを、分けて見る。** 評判の店で食べても、何も立たないことがある。「価値がある」という判断は多くの人のあいだで並ぶが、その人に立った価値そのものは、別の人へ移らない。
