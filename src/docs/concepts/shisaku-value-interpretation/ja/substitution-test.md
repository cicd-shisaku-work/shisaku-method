# 置換の検査

本書の読みを既存の学説・概念に置き換えて、何がそのまま成り立ち、何が置き換えた先に無いかを書く。どこが一致し、どこを著者が導出したかは、著者の見立てである。置き換えた先の学説は、本書と同じことを、多くの場合もっと厳密に説明している。確かめたい読み手は、そちらを読めばよい。**本書が差し出すのは、説明の新しさではない。それを日常に落とし、自分の手で扱える形にすることである。**

**主観価値説・限界効用に置き換える。** 「価値は物の属性ではなく、財と人の必要との**関係**に生じる」は、そのまま成立する。置き換えた先に無いのは、**その関係の中身の読み**である。主観価値説・限界効用は関係を必要と満足で書く。本書は**照合**——予測モデルが出した期待と、入ってきたものの突き合わせ——として読み、そこに伴って**身体に現れるもの**の上に価値を置く。

**知覚価値に置き換える。** 「価値は受け手の側に立つ」は、そのまま成立する（Zeithaml 1988 ほか）。置き換えた先に無いのは、**値段を価値の外に置くこと**である。知覚価値は値段を**価値の内側**へ入れる——支払う犠牲として、価値の式の一部にする（Monroe 1990）。本書は値段を価値の外に置き、**別の側（送り手）の予測が減ったもの**として読む。

**参照点依存に置き換える。** 「価値は絶対的な状態ではなく、参照点からの差として評価される」「参照点は期待が決める」は、そのまま成立する。**ここが最も近い。** 置き換えた先に無いのは三点である。参照点依存の価値関数は**結果（利得と損失）の上に定義**されていて、一般の接触を扱わない。**身体に現れる信号そのものを、理論の中心的な記述対象にしていない**（決める場面で働く感情を、結果の評価に基づく意思決定の理論が落としている、という批判がある——Loewenstein ほか 2001）。そして参照点は**パラメータ**であって、期待を出す**実体**ではない。

**労働価値説・辞書の三つ目に置き換える。** 価値を物や労働の側に置く読み（リカード・マルクスほか）は、本書と逆を向く。本書はそれを誤りとは言わず、**取らない**。ここは置き換えの成否ではなく、立場の違いである。

**置き換えた先に無く、著者が導出したもの。**

**価値は、照合に伴って身体に現れる側に立つ。** 受け手の側に置く読みは既にある。**身体に現れるものとして読む**形は、置き換えた先には無かった。

**値段と「価値が高い」は、同じ機構で出たものである。** 送り手の予測が数に減ったものと、受け手の信号が語に減ったもの。**方向の違う二つの減少**として一つの機構で読む形は、置き換えた先のどれにも無かった——効用理論は受け手の状態を効用関数という一つの量に減らし、価格理論は値段を均衡や利幅で説明し、知覚価値は値段を価値の内側へ入れる。**どれも、値段と価値語を同じ減少の機構で並べない。**

置き換えても残るのは、「日常で扱える」の節に挙げたものである。
