# 置換の検査

本書の読みを既存の概念に置き換えて、何がそのまま成立し、何が崩れるかを置く。**成立する部分に、本書の核は無い。**

**主観価値説・限界効用に置き換える。** 「価値は物の属性ではなく、財と人の必要との**関係**に生じる」は、そのまま成立する。ここに核は無い。崩れるのは、**その関係の中身**である。向こうは関係を必要と満足で書く。本書は**照合**——予測モデルが出した期待と、入ってきたものの突き合わせ——として読み、そこに伴って**身体に現れるもの**の上に価値を置く。

**知覚価値に置き換える。** 「価値は受け手の側に立つ」は、そのまま成立する（Zeithaml 1988 ほか）。ここにも核は無い。崩れるのは**値段の置き場**である。向こうは値段を**価値の内側**へ入れる——支払う犠牲として、価値の式の一部にする（Monroe 1990）。本書は値段を価値の外に置き、**別の側（送り手）の予測が減ったもの**として読む。

**参照点依存に置き換える。** 「価値は絶対的な状態ではなく、参照点からの差として評価される」「参照点は期待が決める」は、そのまま成立する。**ここが最も近い。** 崩れるのは三点。向こうの価値関数は**結果（利得と損失）の上に定義**されていて、一般の接触を扱わない。**身体に現れる信号そのものを、理論の中心的な記述対象にしていない**（心理学の側から、心理的な説明を欠き情動を落としているという批判がある）。そして参照点は**パラメータ**であって、期待を出す**実体**ではない。

**労働価値説・辞書の三つ目に置き換える。** 価値を物や労働の側に置く読みは、本書と逆を向く。本書はそれを誤りとは言わず、**取らない**。ここは置き換えの成否ではなく、立場の違いである。

**置き換えても残るもの（二つ）。**

**価値は、照合に伴って身体に現れる側に立つ。** 受け手の側に置く読みは既にある。**身体に現れるものとして読む**形は、置き換えた先には無かった。

**値段と「価値が高い」は、同じ機構で出たものである。** 送り手の予測が数に減ったものと、受け手の信号が語に減ったもの。**方向の違う二つの減少**として一つの機構で読む形は、置き換えた先のどれにも無かった——効用理論は受け手の状態を効用関数という一つの量に減らし、価格理論は値段を均衡や利幅で説明し、知覚価値は値段を価値の内側へ入れる。**どれも、値段と価値語を同じ減少の機構で並べない。**

構成要素はいずれも既知である。新しいのは、それらの関係構造への圧縮であって、要素そのものではない。
