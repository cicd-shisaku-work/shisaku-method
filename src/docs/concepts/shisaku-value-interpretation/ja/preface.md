# はじめに

本書は、価値とは何かを証明するものではない。**私（シサク）が、価値をどう見ているか**という、一表現者の解釈である。

真偽ではなく、**効くかどうか**——このレンズで見たとき、**自分が差し出したものが、相手の側で価値として立つかどうか**を自分の手で扱えるようになるか、で読んでほしい。合わなければ、別の解釈を選べばいい。解釈を受け入れるかどうかは読者の内にある自由であり、その簒奪も侵犯も望まない。私は裁定者ではなく、一人の表現者として、これを差し出す。

**射程。** 本書は、人類と、人類が置かれている状況について書く。

**借りている語。** 〔シサク・予測モデル解釈〕から**予測モデル**（期待を先に出す側の実体）と**次元**（独立に変わりうるものの数）を、〔シサク・クオリア解釈〕から**照合**（予測モデルが出した期待と、入ってきたものを突き合わせること）と**接触**（入ってきたもの）を借りる。それ以外の系列の語は借りない。

本書は誰にでも掛かる一般理論として立てていないので、**反証条件を置かない**。代わりに、既存の概念に置き換えて何が残るかの検査を末尾に置く（第4節）。
