# はじめに

本書は、価値とは何かを証明するものではない。**著者（シサク）が、価値をどう見ているか**という、一表現者の解釈である。

著者は、真偽ではなく、**価値が出るかどうか**で、本書を読んでほしいと願っている。読み手に着眼してほしいのは、読み手自身が差し出したものである——それが相手の側で、どう立つか、立たないか。合わなければ、別の解釈を選べばいい。解釈を受け入れるかどうかは読み手の内にある自由であり、その簒奪も侵犯も望まない。著者は裁定者ではなく、一人の表現者として、これを差し出す。

**射程。** 本書は、人類と、人類が置かれている状況について書く。

**借りている語。** 〔シサク・予測モデル解釈〕から**予測モデル**（期待を先に出す側の実体）と**次元**（独立に変わりうるものの数）を、〔シサク・クオリア解釈〕から**照合**（予測モデルが出した期待と、入ってきたものを突き合わせること）と**接触**（入ってきたもの）を借りる。それ以外の系列の語は借りない。

（ただし、真偽で読まないことは、訂正できないということではない。個々の見立ては、使う中で試され、更新されていく。）
