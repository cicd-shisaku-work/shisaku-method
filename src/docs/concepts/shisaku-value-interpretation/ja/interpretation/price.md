# 値段には、送り手の予測が一つの数になって入っている

山頂で、ジュースが五百円で売られているとする。その五百円は、いくつものことが**一つの数になった**結果である。運ぶ手間。そこでしか買えないこと。売れるかどうかの見込み。**その見込みの中に、受け手についての予測が入っている。**

**そして、その予測が何であったかは、数の側からは取り出せない。** 一文で言い直せるなら、それは減っていない。**減っているから、数になっている。**

値段は、誰にとっても同じ数である。**共有できる。** 価値は、**受け手の外へ、そのまま移せない。** 同じものを多くの人が「価値がある」と言うことはある——**判断は並ぶ。** だが、その人に立った価値そのものが、別の人へ移るのではない。

**値段には、ほかのものも入る。** 挙げられるものは候補であって網羅ではなく、候補どうしが独立かも未証明である。**中身と例は補足〔`shisaku-value-interpretation-three-words-map.md`〕が担う。** 本書が読むのは、そこに受け手についての予測が入っていて、それが一つの数に減っている、という一点である。

そして**予測が外れれば、売れ残る。** 減らして出した数が、受け手の側に立たなかった、ということである。
