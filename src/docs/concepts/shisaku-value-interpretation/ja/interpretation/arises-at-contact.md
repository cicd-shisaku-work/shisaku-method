# 価値は、接触で生じる

価値は、物の側にも、人の側にもない。**送り手が出したもの**——表現でも、物でも——が受け手に触れ、受け手の予測モデルとのあいだで**照合**が起きる。**その照合に伴って身体に現れるものの上に、価値は生じる。**

**価値は、クオリアとは別に生じるものではない。** 〔シサク・クオリア解釈〕が信号と呼ぶそのものを、本書は「価値」という語で読んでいる。**別の実体を置いているのではない。**

**ただし、すべての信号が価値として読まれるわけではない。** 差し出されたものとの照合で生じた信号を、本書は価値と呼ぶ。痛みも驚きも身体に現れるが、それらを価値と呼ぶかどうかは、**何との照合で生じたか**による。

だから価値は移らない。同じ物でも、ある人には価値が高く生じ、ある人には生じず、ある人には無い。**個人差は、この読みの欠陥ではなく、帰結である。**
