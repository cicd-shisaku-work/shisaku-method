# 富士山のジュースと、炭酸が苦手な人

山頂で、五百円のジュースが売られているとする。

水筒が空の人には、価値が高く生じる。満タンの人には生じない。**物も、値段も、同じである。** 違うのは受け手の状態で、そこで照合が起きている。**売り手が置いたのは一つの数である。** その中に何が入っていたかは、数の側からは取り出せない。

炭酸が苦手な人は、水筒が空でも買わないことがある。**ここでは状態が満たされていない——渇いている——のに、価値が生じない。** 源が違うからである。

**この二つは、外からは同じ「売れなかった」に見える。** 違うのは、生じなかった側である——一方はその人の状態、もう一方はその人の内に留まるもの。
