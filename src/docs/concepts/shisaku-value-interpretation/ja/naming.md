# 系列の中で、この語をこう名指す

**指すもの。** 接触に伴って、受け手の側に立つもの。受け手の外へそのまま移せない。

**指さないもの。** 物の属性。送り手が打つ数。クオリアとは別の実体。そして、受け手の内に留まるものの構造——**何を選び取ってきたかがどう形づくられるかは、本書の扱うところではない**。本書が扱うのは、それが接触の側でどう働くかだけである。

**三語の線を、ここで引く。**

- **価値**——接触に伴って受け手の側に立つもの。**受け手の外へ、そのまま移せない。**
- **値打ち**——共有できる物差しで、外から測るもの。**測る側が物差しを持ち込み、その物差しは人が変わっても同じ形で当てられる。** 日常の語はここまで細かく分けないので、**この線は本書が引いたものである。**
- **値段**——送り手が、受け手に生じるだろう価値についての予測を、**一つの数に減らしたもの**。

**既存の用法との関係。** 本系列は、この二つを同じものに使ってきた箇所がある——外から測るものを「価値」と呼び、受け手に立つものも「価値」と呼ぶ。**本書が線を引くので、外から測る側は「値打ち」で読む。**

**予測モデル・次元・照合の正本は、本書ではない。** それぞれ〔シサク・予測モデル解釈〕と〔シサク・クオリア解釈〕にある。
