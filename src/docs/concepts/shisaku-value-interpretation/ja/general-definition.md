# 一般にはこう定義されている

辞書は、価値をおおよそ三つの意味で載せている。**役に立つ度合い**（有用性）。**交換されるときの値打ち**。そして、**個人や社会を通じて承認されるべき絶対的なもの**。

経済学と心理学には、より細かい読みがある。

**主観価値説・限界効用**（メンガーら 1871 以降）は、価値を物の属性として持たない。**財と、人の必要との関係**に生じるとする。**知覚価値**の系では、価値は「消費者が、**受け取るものと与えるものの知覚にもとづいて下す**、製品の効用についての総合的な評価」とされる（Zeithaml 1988）。**参照点依存**（Kahneman & Tversky 1979）は、価値を絶対的な状態の上ではなく、**参照点からの差**として評価する——そしてその参照点は、期待と文脈が決めるとされる（Kőszegi & Rabin 2007）。

**本書がここから引くのは、そこまでである**——価値は物の側の属性ではない、というところまで。本書が読み替えるのは、その先である。**それがどこで生じ、値段とどう違うのか。**
