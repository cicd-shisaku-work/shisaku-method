# 測る側が物差しを持ち込んでいるか

持ち込んでいれば**値打ち**である。測る側が外から当てる物差しがあり、その物差しは人が変わっても同じ形で当てられる。だから並べられる。

**この線は、本資料の親が引いたものである。** 日常の語はここまで細かく分けない。「値打ちがある」と「価値がある」は、ふだん同じ意味で使われる。

**例——中古車の査定。** 年式、走行距離、修復歴。**査定する側が物差しを持ち込み、誰が当てても同じ形で当たる。** だから並べられる——同じ年式の二台を、同じ表で比べられる。

この一台には、三つが別々に立っている。**査定額は値打ち**（外から当てた物差しの結果）。**売値は値段**（売り手が置いた一つの数）。そして**手放したくない、という側が価値**である。三つは違う数になりうるし、違っても誰も間違っていない。
