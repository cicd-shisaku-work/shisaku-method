# 原典へのフィードバック候補

作成中に露見した、原典〔シサク・価値解釈〕への差し戻し候補をここに落とす。

- **条件の順序（数の側から先に当てる）を原典へ上げるかは、上げない。** 原典が引いているのは三語の線であって手続きではなく、手続きを上げ始めると補足の仕事が原典へ戻る（規約「補足の必須様式」の節が、検査手続きを補足の持ち物にしている）。**順序は本資料「判定」の節が持つ。** ただし、順序を知らない原典の読者には、「受け手の側に立っていて、外へ移せないか」から当てて値段まで価値と読む余地が残る——この余地は残したまま置く。
- **「値打ち」の例は、本資料「測る側が物差しを持ち込んでいるか」の節に置いた**——中古車の査定（査定額が値打ち、売値が値段、手放したくない側が価値）。原典の側には無いが、**例は補足が担う**（規約「原典が置くもの／置かないもの」の節）ので、差し戻しにはしない。
- **二つの源の境目が非固定であることは、原典が書いている**——「個人差は、二つの側から来る」の節が「二つの側の境目も固定していない（どちらにも掛かる場面がある）」と置いた。本資料の作成中はまだ無く、差し戻し候補として挙げた項目である。**反映済み。**
