# 値段に入るものの候補

原典は「いくつものことが一つの数になった」とだけ書き、中身を置いていない。ここに候補を並べる。

- **運ぶ手間**——そこまで持っていくのに掛かったもの。
- **競うこと**——ほかにも売る者がいるかどうか。
- **希少さ**——数が限られているかどうか。
- **決まりごと**——値の付け方に外から掛かる枠。
- **売れるかどうかの見込み**——**この中に、受け手についての予測が入っている。**

**ここに挙げたものは候補であって、網羅ではない。** 候補どうしが独立かどうかも、この立て方で閉じているかも、未証明である。

**そして、どれがどれだけ入ったかは、数の側からは取り出せない。** 五百円という数を見ても、そのうち何が運ぶ手間で、何が見込みだったかは分からない。**一文で言い直せるなら、それは減っていない。** 候補を並べることと、数から復元できることは、別である。
