# 接地

**以下は傍証であって、証明ではない。** 原典は一つの解釈として立っており、外の事実で倒れる形をしていない。ここに並べるのは、外の記述と原典の読みが、どこで重なりどこで離れるかの目印である。

- **主観価値説・限界効用**（メンガーら 1871 以降）。価値を物の属性ではなく、**財と人の必要との関係**に置く。**受け手の側に置く、という大枠はここに先例がある。** 離れるのは、関係の中身を照合として読み、身体に現れるものの上に置く点。
- **知覚価値**（Zeithaml 1988・Monroe 1990 ほか）。価値を「受け取るものと与えるものの知覚にもとづく総合的な評価」とする。**離れるのは値段の置き場である**——知覚価値は値段を価値の式の内側（支払う犠牲）に入れ、原典は外に置く。**本資料の一つ目の条件は、この違いをそのまま手続きにしたものである。**
- **参照点依存**（Kahneman & Tversky 1979／Kőszegi & Rabin 2007）。価値を参照点からの差として評価し、参照点は期待と文脈が決めるとする。**照合にもっとも近い。** 離れるのは、参照点依存の価値関数が結果（利得と損失）の上に定義されていること、**身体に現れる信号そのものを理論の中心的な記述対象にしていない**こと、そして参照点がパラメータであって期待を出す実体ではないこと。
- **労働価値説**。価値を物や労働の側に置く。原典はこれを誤りとせず、**取らない**。立場の違いであって、置換の成否ではない。
