# 位置づけ

本資料は**地図**である。〔シサク・価値解釈〕が線を引いただけで中身を置かなかったもの——**三語をどう切り分けるかの手続き、値段に入るものの候補、価値が立たない場面の候補、そして接地**——を受ける。

**不変の地図であって、実装のプロファイルではない。** 判別子は一問——**道具や運用の形を変えても起きるか。** 起きるならここに置く。特定の商いの形、特定の値付けのやり方でしか起きないなら、ここではない。

原典が持つのは機構（価値は照合に伴って受け手の側に立つ。値段と「価値が高い」は同じ減少の別方向）。**本資料が持つのは、目の前のものがどれなのかを決める手続きと、それぞれの枡に入る候補である。**
