# 置換の検査

本書の読みを既存の概念に置き換えて、何がそのまま成立し、何が崩れるかを置く。**成立する部分に、本書の核は無い。**

**制御の二分法に置き換える。** 「変えられるものと変えられないものを分け、変えられるものに向かう」（エピクテトス）は、そのまま成立する。各人の前提は変えられる側にあり、社会の仕組みは変え難い側にある。ここに核は無い。崩れるのは、**因果の向き**である。制御の二分法は、変えられるものと変えられないものの関係を言わない。本書は、変えられる側（各人の前提）の集合が、変え難い側（仕組み）の振る舞いを上から抑えている、と言う。

**方法論的個人主義に置き換える。** 「社会は個人の行為の集積である」は、そのまま成立する。ここにも核は無い。崩れるのは二点。方法論的個人主義は、個人の行為から社会を説明するが、**個人の前提が更新できる**とは言わない。本書は、各人の前提が、点検と更新で動く側にあることを核に置く。そして方法論的個人主義は、**上界**を言わない——集積であることと、集積の質が仕組みの振る舞いを上から抑えることは、別の主張である。

**システム思考に置き換える。** 「構造が振る舞いを決める」は、そのまま成立する。**ここが最も近い。** 崩れるのは、構造の中身である。システム思考は構造を、要素どうしの関係とフィードバックとして書き、介入点を構造の中に探す。本書は、その構造に、**それを運用する各人の前提**が含まれている、と読む。構造を設計し直しても、設計し直す人と使う人の前提が同じなら、同じ振る舞いが戻る——この上界は、構造を人の外に置く読みからは出ない。

**人的資本論に置き換える。** 「教育は個人の生産性を高め、社会の成果を上げる」は、そのまま成立する。崩れるのは、**教育の中身**である。人的資本論は教育を、知識と技能の蓄積として読む。本書は教育を、各人が自分の前提を点検し、更新する力を持てるようにすること、と読む。知識を足しても、それを読む前提が変わらなければ、上界は動かない。

**制度設計論に置き換える。** 「制度の設計が人の行動を変える」は、そのまま成立する。制度設計論は、設計の側から人を動かす。本書は、その向きを否定しない——輪の片側である。崩れるのは、**上界**である。設計は、それを運用する各人の前提の質を超えては、行動を変えない。設計で変えられる範囲の外側を、本書は言っている。

**社会システム論に置き換える。** 「社会の仕組みは、人の意図を離れて自律に作動し、人をその部品として組み込む」は、そのまま成立する——官僚制、市場、アルゴリズム。崩れるのは、**その自律の読み方**である。社会システム論は自律を仕組みの側の性質として読む。本書は、それを、各人が仕組みの差し出す圧縮概念を点検せずに受け取り、手綱を手放して前提として作動させている状態の集合として読む。仕組みが人を規定しているように見えるとき、上界は消えているのではなく、低い。

**文化・規範に置き換える。** 「人の側の差は文化と規範の差である」は、そのまま成立する。崩れるのは、**その所在**である。文化も規範も、各人が担いでいる圧縮概念であり、各人の内で前提として作動している。文化を人の外に置くと、それは変え難い側へ移り、制御の二分法の変えられない側に落ちる。本書は、文化を各人の前提の集合として読み、変えられる側に置く。

**置き換えても残るもの（三つ）。**

**上界。** 仕組みには設計だけでは超えられない運用上の上限があり、それが、仕組みを作り、運用し、改修する各人の前提で決まること。構造の中に各人の前提を含める読みは、置き換えた先には無かった。

**暫定と恒久の線。** 仕組みの改修が上界の内側で効き、上界を動かすには各人が手綱を握れる状態を作るところまで輪の全体を変えることが要ること。制度だけの修正と、人を含む輪の全体の修正を、優劣でなく時間軸で分ける形は、置き換えた先のどれにも無かった。

**教育の中身。** 知識の蓄積でなく、各人が自分の前提を点検し更新する力を仕組みにすること。〔シサク認知フレーム理論〕の「知識ではなく、レンズである」を、社会のスケールで言い直したものである。

構成要素はいずれも既知である。本書が置く新しさは、それらをこの関係構造に圧縮し、そこから上界という読みを導くところにあって、要素そのものにはない。
