# 輪の中の梃子

仕組みと各人の前提は、輪をなしている。各人の前提の集合が仕組みを生み、仕組みが各人の前提を育てる。本書は、この輪の片側だけを言っているのではない。仕組みが人を育てる向きは、確かにある——教育が、まさにその向きの仕組みである。

本書が言うのは、この輪のどこに梃子を置くか、である。仕組みの設計を直す梃子は、上界の内側で効く。上界を動かす梃子は、各人が己の手綱を握れる状態を作る仕組み——すなわち、**人間をどう解釈するかと、その解釈を各人が自分で更新する方法とが、仕組みになっていること**——にある。これが、本書の言う教育である。知識を足すことではない。自分の前提を点検し、更新する力を、各人が持てるようにすることである。

〔シサク・世界解釈〕は、人類が置かれている状況を見取り、どう昇華し、どんな枠で違和感を読み解くかの技術は別に書かれる、と範囲の外に置いた。シサクメソッドは、その別に書かれるものの一つの試みである。本リポジトリが fork を前提に公開されているのは、この帰結の実装である——言語化したものを差し出し、各人がそれを自分の Book of Knowledge として更新する。それは、恒久対応を、一人分ずつ、仕組みにしようとする試みである。

本書の主張の強さは、三段に分かれている。**例で示せるのは、上界まで**である。**人の側の差を各人の手綱で読むのは、本書が置く解釈**であり、置換の検査で守る。そして、**恒久対応が効くかどうかは、本書は示さない**——それは下流にしかなく、公開された実装と、それを fork した各人の側にしか現れない。
