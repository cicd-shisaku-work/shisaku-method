# 同じ仕組み、違う人、違う結果

上界は、次の形の例で試せる。**仕組みを固定して、運用する人の集合だけを変えると、結果が変わるか。**

交通規則を見る。国が違っても、道路の規則の骨格はほとんど同じである。信号、優先、制限速度、追い越しの側——旅行すれば、規則の同一性は自分で確かめられる。それでも、道路の振る舞いは国ごとに、地域ごとに、人ごとに違う。譲るか、割り込むか、速度をどう読むか。規則は同じで、違うのは、ハンドルを握っている各人である。ここでは、手綱は比喩でさえない。

これを「文化の違い」「取り締まりの強さ」と読むこともできる。だが、文化も規範も、各人が担いでいる圧縮概念であり、取り締まりへの反応も、各人の前提から出る判断である。文化を持ち出すことは、上界を否定するのでなく、各人の前提が集合として似る、と言っているにすぎない。

もう一つ、小さな仕組みで見る。同じ規程を持つ組織で、ある部署ではそれが目的どおりに回り、別の部署では形骸化する。規程は同じで、違うのは、それを読み、運用する人の集合である。組織で働いたことのある読者は、この形を自分の場所で見つけられるだろう。

これらの例が示すのは、上界までである。人の側の差を、各人の手綱で読むのは、例が証明することではなく、本書が置く解釈である。
