# 日常で扱える

この節に挙げるのは、著者が日常で扱えると考えている形であって、処方ではない。著者自身、その都度選んで使っている。

**仕組みがうまく回らないとき、設計だけを見ない。** 同じ規程を持つ職場で、ある部署では目的どおりに回り、別の部署では形だけになっているとする。違うのは規程ではなく、それを読んで動かしている人たちかもしれない、と考えてみる。

**直したのに同じことが起きたら、直したのが紙の上だけだったかを見る。** 手順書を書き直したのに、半年後に同じ抜けが出たとする。現場では、書き直す前と同じく「急ぐときは確認を飛ばしてもいい」と思われていたのかもしれない。手順書は変わっても、その一言は変わっていなかった。

**「仕組みが悪い」と言いたくなったとき、自分がその仕組みのどこで判断しているかを見る。** 同じ条文を、「目的は何だろう」と読む人もいれば、「抜け道はどこだろう」と読む人もいる。自分も、その読む人の一人だと考えてみる。

**自分の手綱から始める。** 会議で、新しいやり方に反射的に反対したくなったとする。相手と自分が、それぞれ何を当然としているかを考えてみる。当然としているものがずれているから、反対したいのかもしれない。議論すべきは目の前の案か、互いの当然か——それを確かめることから始める。自分の側は、今日から点検できる。
