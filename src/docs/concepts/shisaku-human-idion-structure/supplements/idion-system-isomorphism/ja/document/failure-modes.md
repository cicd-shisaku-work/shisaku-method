# 失敗機構

比喩語を原典に入れると、原典がヒトの IDION の理論から計算機の理論に見え、把手を日常語で当てなかった理由（輸入された含意で概念が縮む）を自ら破る。逆に同型を使わないと、原典が暗黙に前提している枡（状態・波及点検・抑制）が露わにならない。道具として使い、成果は区別だけを上げる。**同型を法則にしない**——対応表は仮説を生成する装置であって、「人間では必ずこうである」を導く装置ではない（キャッシュのクリア＝変容ゼロ、は人間では成り立つとは限らない）。対応が立つ場所より、対応が切れる場所と「なぜ切れるか」を問うことが、この道具の本体である。
