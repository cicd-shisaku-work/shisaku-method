# 原典へのフィードバック候補

- **重なって読める変容**（捉えられる波長が広がる）——同じ接触から、元の見え方を残したまま、別の層の情報が重なって読めるようになる変容に、原典は名を持たない。正の詳細化（同じ見え方の中で細かくなる）とも、新領域の変容（別の対象）とも違う候補。
- **視野と欠けの区別**——意識していなかった領域を把握する（視野）ことと、格納すら無かった場所に予測モデルが立つ（欠け）ことを、原典は分けていない。
- **見えるものが減る向きの変容の名**——欠ける・ぼける・遠近が潰れるに当たる変容に、原典は名を持たない。原典は「変容はゼロにならない」とするが、減る向きの書き換えの種類は、防御的な書き換えのほかに挙げていない。

（列挙のみ。反映は著者の裁定で、道具非依存の発見だけを原典へ上げる。）
