# 検査手続き

1. 見え方の変化の七つと、その逆向きの変化を、上の表に並べる。変容の種類の列が埋まらない行（名が無い）は、原典に名の無い変容の種類の候補。
2. 原典の変容の種類のうち、左列に対応物が無いものを拾う。IDION がレンズでない点の候補（「対応が切れる場所」の節へ）。
3. 拾った候補を、独立性の二基準に掛ける——(a) 操作可能性（その区別でしか出ない予測があるか） (b) 非重複（原典の既存の区別で説明できないか）。両方を満たすなら原典へのフィードバック候補、片方を満たさないなら本資料の注記に留める。
4. 光学の語を原典に書かない。原典へ上げるのは**区別**であって、対応物の名（曇り・波長）ではない。

**非固定・未証明の明記。** 構成要素の対応と、見え方の変化の種類の対応は候補であって網羅でなく、対応の正しさは未証明である。
