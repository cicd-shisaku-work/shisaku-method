# 構成要素の対応

| レンズの要素 | 原典の要素 | 対応から見えること |
|---|---|---|
| 光 | 接触 | 入ってくるもの。光が差さなければ、レンズの良し悪しは問えない |
| レンズ | 予測モデル | 見え方を決めるのはレンズの側である。同じ光でも、レンズが違えば違う像を結ぶ |
| 像 | 照合の結果 | 光とレンズの組で結ばれる。像は光そのものではない |
| 見る働き | 機構 | 像を読み、判断する。レンズが替わっても、見る働きの形は変わらない |
| レンズが替わる | 変容 | 以後の見え方が変わる。替わったレンズは、次の光を受ける側に回る |
