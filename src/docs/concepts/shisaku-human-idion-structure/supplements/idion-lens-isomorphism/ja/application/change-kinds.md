# 見え方の変化の種類 → 変容の種類

左列は、シサク・世界解釈「見え方が変わる、ということ」の節の見え方の変化の九つ（見えるものが増す向き）である。

| 見え方の変化 | 変容の種類 | システムとの同型で重なる行 |
|---|---|---|
| 視野が広がる | 新領域の変容 | 新設（新しいスキーマ） |
| レンズの欠けが埋まる | 新領域の変容（格納も無かった場所に、予測モデルが立つ） | 新設（新しいスキーマ） |
| レンズの曇りが晴れる | 統合（保留していた違和感が結合して解ける） | 多数の issue の一斉 close |
| 解像度が上がる | 正の詳細化／精緻化＝境界の明示 | 新機能の追加／モジュールの分割 |
| 捉えられる波長が広がる | 同じ像に、別の層の情報が重なって読める（元の見え方は残り、読めるものが一枚加わる） | —（重なる行が無い） |
| 遠近が立つ | 結合（A と B を包む一段上の構造 C が立ち、どれが上流かが見える） | 共通の基底の抽出 |
| 自分のレンズが見える | 自己解釈の書き換え（自分の認知の方式を発見する） | 自分のコード・設定を読む（リフレクション）。ただしシステムは開けば読め、人は出力のずれから後で気づく——〔idion-system-isomorphism.md〕「対応が切れる場所」の節の「内からの読み取り」で切れる |
| 焦点が合う | 着眼の構造の書き換え（目が着く所が定まり、ぼんやりしていたものの輪郭が立つ） | インデックス・クエリの書き換え（姉妹補足の、構成要素の「着眼の構造」の行） |
| ズームの幅が広がる | 着眼の構造の書き換え（寄り引きの幅が広がり、寄れなかった細部に寄れ、見渡せなかったものを見渡せる） | インデックス・クエリの書き換え（姉妹補足の、構成要素の「着眼の構造」の行） |

**視野とズームの境。** 視野は、注意が向きうる範囲——意識に上がりうる領域がどこまでか——である。ズームの幅は、意識に上がっている領域の中で、どの細かさ・どの広さまで寄り引けるか——着眼の構造（着眼優位理論）——である。視野が広がると、それまで無かった領域が見えるようになる。ズームの幅が広がると、同じ領域を、より細かく、より広く見られるようになる。引いた幅と、目を着ける先の組で、上がる抽象が決まる（着眼優位理論「引く幅と、目を着ける先で、抽象が立つ」の節）。

**逆向きの変化。** 上の九つは、見えるものが増す向きだけを挙げる（正本のシサク・世界解釈が、見え方の変化を価値として立てているため）。レンズには、九つのそれぞれに逆向きの変化がある。逆向きの変化の語は本資料の語であり、正本からは引いていない。

| 逆向きの変化 | 変容の種類 | システムとの同型で重なる行 | 対になる変化 |
|---|---|---|---|
| 視野が狭まる（意識していた領域が外れる） | 名が無い（意識に上がっていた領域が外れる。新領域の変容の逆） | 削除（スキーマの廃止。版管理の下では、削除も履歴に残る） | 視野が広がる |
| レンズが欠ける（光が差さなくなる） | 名が無い（ある領域で、予測モデルが働かなくなる） | データの消失（一部が失われ、参照できなくなる） | レンズの欠けが埋まる |
| レンズが曇る（捉えていたものが捉えられなくなる） | 違和感が立つ（説明できていたものが説明できなくなり、保留が始まる） | issue の起票 | レンズの曇りが晴れる |
| 解像度が下がる（ぼける） | 名が無い（細かく分けていた判定が、粗い一律に戻る） | 機能の削除／モジュールの統合 | 解像度が上がる |
| 波長が遮られる（フィルターが掛かる） | 防御的な書き換え（ある種の接触を避け、近づくと身構える） | 入力の遮断（特定の入力を弾く設定） | 捉えられる波長が広がる |
| 遠近が潰れる（どれも同じ距離に並ぶ） | 名が無い（結合が効かず、並存に戻る） | 基底の解体（共通部分をばらして各所に複製する） | 遠近が立つ |
| 自分のレンズが見えなくなる（レンズ越しだと忘れ、像を世界そのものと取る） | 定常化（書き換わった予測モデルが当然になる。シサク・ヒト変容理論の補足〔shisaku-human-transformation-process-stages.md〕の定常化段） | 設定の既定値化（変えた設定が既定として意識されなくなる） | 自分のレンズが見える |
| ピントがずれる（輪郭が立っていたものが、ぼやける） | 着眼の構造の書き換え（目が着いていた所から外れる） | インデックス・クエリの書き換え（姉妹補足の、構成要素の「着眼の構造」の行） | 焦点が合う |
| ズームの幅が狭まる（寄れていた細部に寄れず、見渡せていたものを見渡せなくなる） | 着眼の構造の書き換え（寄り引きの幅が狭まる） | インデックス・クエリの書き換え（姉妹補足の、構成要素の「着眼の構造」の行） | ズームの幅が広がる |

**対の外の変化。** どの九つの逆でもない変化もある。

| レンズの変化 | 変容の種類 | システムとの同型で重なる行 |
|---|---|---|
| 屈折が変わる（像が逆さになる） | 反転の詳細化（一律だった判定が逆転する） | 改修（仕様変更） |

**掛け方。** 見え方の変化そのものではなく、見え方の変化へ至る道もある。

| 掛け方 | 何が起きるか | 原典の当て | システムとの同型で重なる行 |
|---|---|---|---|
| 二つの像を重ねる（双眼） | 二つの像のずれから、奥行きが立つ——遠近が立つ道 | 結合（二つの予測モデルが同じ前提に触れ、両方を包む一段上の構造が立つ。シサク・ヒト IDION 構造理論「累積の結合則」の節） | 共通の基底の抽出 |
| 異なる二枚のレンズを同時に掛ける（ハイブリッド） | 二つの像を、まとめずに並べて持とうとする。例：倫理を、昔ながらの物語の基準で読みつつ、進化心理学でも見る | 保留（二つの予測モデルが、矛盾したまま残る。シサク・ヒト IDION 構造理論「累積の結合則」の節「矛盾は弱さでない」——深い保留） | —（重なる行が無い） |
