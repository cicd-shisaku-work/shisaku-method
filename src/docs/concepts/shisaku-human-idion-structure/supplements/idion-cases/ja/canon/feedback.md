# 原典へのフィードバック候補

- **駆動の層の置き場**——本理論の構造の節に置いたが、駆動は IDION の下であり、上位（世界解釈の BIOS／OS の駆動）と同じものを指している可能性がある。〔v0.3：駆動は IDION の中（予測モデルと機構を動かす部分）に置いた。上位の BIOS との関係は残る〕。二重定義になっていないかの検査。
- **（閉じた）深さ＝変容の距離と、シサク・ヒト変容理論の「深さ＝層」**——同じ軸の解像度の違い（層は目安・距離は連続）。上位理論側で一句揃える。——同理論 v0.2 が深さを変容深度・変容広さ・在庫に分け、層を「何が書き換わったか」の対象とした（同理論「命題と、変容の定義」の節・〔idion-axes-map.md〕の帳簿注記）。
- **変容の定義を「何が書き換わったか」で再整理する射程**——受容／合理化を層の名として置くなら、変容そのものの定義（シサク・ヒト変容理論）に触れる。上位理論側。
- **（閉じた）主体＝駆動層＋IDION**——シサク・ヒト変容理論のパイプラインの「主体（クオリア発生・欲求）」が、駆動層と IDION の二層に割れる。上位理論側。——同理論 v0.3.1 が、主体を IDION と両端点で特徴づけた。駆動は IDION の身体駆動（IDION の三つ目の部分）である（同理論「主体と、四つの構造」の節）。
- **（閉じた）層は目盛りか対象か**（事例19・20）——原典の層（着眼・判定軸・自己像・世界解釈）は深さの目盛りでなく「何が書き換わったか」の対象であり、深さ（判定を動かした境界の量）は別軸、という読み。シサク・ヒト変容理論「命題と、変容の定義」の節の「深さ＝どの層まで及ぶか」と連動するため上位理論側。候補の地図は〔idion-axes-map.md〕。——対象で決着した（原典「未決」の節・〔idion-axes-map.md〕の帳簿注記）。
- **受容／合理化／精緻化**（事例20）——判定軸の書き換えには、ラベルを一律に反転させる形（A は実は OK）と、展開して条件付きにする形（一律でない）がある。前者を合理化、後者を精緻化と弁別できる可能性。変容の定義（シサク・ヒト変容理論「命題と、変容の定義」の節）に触れるため上位理論側。固定しない。
- **（閉じた）受け手側の写像**（事例20）——受け手が「深い」と感じる条件（自分の一律判定に境界が立つ）は、表現者の深さ（判定を動かした境界の量）の写像になっている。IDION から表現信号への写像（原典の未解決）に一本の線を引く候補。出口側（シサク・ヒト表現構造理論・シサク・ヒト共鳴構造理論）との交点。——受け手が辿った量は、シサク・ヒト変容理論の補足〔shtt-depth-terms.md〕の共鳴深度が引き取った（〔idion-axes-map.md〕の帳簿注記）。
