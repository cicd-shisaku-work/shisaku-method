# 原典へのフィードバック候補

- **駆動の層の置き場**——本理論の構造の節に置いたが、駆動は IDION の下であり、上位（世界解釈の BIOS／OS の駆動）と同じものを指している可能性がある。二重定義になっていないかの検査。
- **深さ＝変容の距離と、SHTT の「深さ＝層」**——同じ軸の解像度の違い（層は目安・距離は連続）。上位理論側で一句揃える。
- **変容の定義を「何が書き換わったか」で再整理する射程**——受容／合理化を層の名として置くなら、変容そのものの定義（SHTT）に触れる。上位理論側。
- **主体＝駆動層＋IDION**——SHTT のパイプラインの「主体（クオリア発生・欲求）」が、駆動層と核の二層に割れる。上位理論側。
- **層は目盛りか対象か**（事例19・20）——原典の層（着眼・判定軸・自己像・世界解釈）は深さの目盛りでなく「何が書き換わったか」の対象であり、深さ（判定を動かした境界の量）は別軸、という読み。SHTT §1 の「深さ＝どの層まで及ぶか」と連動するため上位理論側。候補の地図は〔idion-axes-map.md〕。
- **受容／合理化／精緻化**（事例20）——判定軸の書き換えには、ラベルを一律に反転させる形（A は実は OK）と、展開して条件付きにする形（一律でない）がある。前者を合理化、後者を精緻化と弁別できる可能性。変容の定義（SHTT §1）に触れるため上位理論側。固定しない。
- **受け手側の写像**（事例20）——受け手が「深い」と感じる条件（自分の一律判定に境界が立つ）は、表現者の深さ（判定を動かした境界の量）の写像になっている。IDION から表現信号への写像（原典の未解決）に一本の線を引く候補。出口側（SHEST・SHKST）との交点。
