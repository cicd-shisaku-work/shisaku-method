# 形態の候補

変容コストは一種類でない。候補——

| 形態 | 何が起きているか | 原典の対応 | 事例（idion-cases） |
|---|---|---|---|
| **闘い（防衛）** | 書き換えが自己像・既存の判定を否定し、駆動が要求を押し返す。恐怖・自己否定・過去の判断の誤り・自己喪失の恐怖と一つずつ反論する | 構造の節「抵抗との闘い」 | 事例15（禁じていた欲求） |
| **闘い（慣性）** | 駆動が向かう先へ、身体・習慣が追いつかない。反復し、諦めず、微小に書き換える | 同（抵抗の二つの向き） | 事例19（料理人） |
| **闘い（規範離脱）** | 否定する対象が自分の判定でなく、世間の常識・道徳・所属集団の規範についての、本人の予測モデル。「みんながそう言っているのに自分だけ」 | 同（否定する対象の一つ） | 事例20（反転の詳細化） |
| **統合** | 保留していた違和感が、後の接触で結合して解ける。既存の判定を否定しない（空白が埋まる）。一気の再構成 | 構造の節「統合」・結合則 | 事例18（一冊で解ける）・事例17 |
| **探索** | 説明できない接触を抱えたまま、照合を繰り返す。保留を持ち続ける負荷 | 保留・結合の契機 | 事例17・18 |
| **反復・身体の調整** | 手・身体の側の書き換え。境界が身体に刻まれる | 同（慣性）・変容量の節「種類を問わない」 | 事例2・3・19 |
| **感情の処理** | 接触が立てた感情を、予測モデルが受け止められる形に置き直す | 構造の節（駆動・違和感） | 事例7（回顧録） |
| **自分についての予測モデルの更新** | 世界・他者の解釈が自己へ波及し、自己像の側で再び要求が立つ | 構造の節「過程は一周で終わらない」 | 事例20 |

**固定しない。** 形態は排他でなく、一つの変容の中で交互に現れる（料理人の「こうじゃない」と「これはいい」＝闘いと統合が同じ過程の局面）。形態は変容の**種類**でなく、過程の**局面**として読む。
