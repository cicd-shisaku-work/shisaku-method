# 形を決める変数（候補）

原典が置く変数は二つ——

- **否定する量**——書き換えが、既存の判定・自己像・共有していた規範をどれだけ否定するか。正の詳細化（既存の判定を維持したまま解像度が上がる）は否定ゼロで統合の形をとり、反転の詳細化（判定が逆転する）は否定が大きく闘いの形をとる。
- **慣性**——身体・習慣が追いつくまでの反復。

これに、本資料が候補として足す変数——

- **帰属（自己への近さ）**——書き換え対象が自己に近いほど否定する量が大きくなりやすい（現象＜他者解釈・世界解釈＜判定軸＜自己解釈＜自己規定、の目安。絶対的な階層ではない——世界解釈が自己モデルへ波及すれば痛む）。〔idion-axes-map.md〕と共有。
- **局面**——同じ変容の中で、世界の解釈が変わる段は快く、自己の過去の判断へ届く段で痛む。形は時間で切り替わる。
