# 検査手続き

形態の候補を足すときは、独立性の二基準で見る——(a) **操作可能性**：その形態でしか出ない予測があるか（例：慣性の闘いは「一日の抵抗は小さいのに累積の深さが大きい」を予測する。防衛の闘いは「抵抗の大きさが自己像への近さに比例する」を予測する）。(b) **非重複**：他の形態や、原典の既存の区別（保留・結合・格納）で説明できないか（例：「探索」は「保留を持ち続ける」と重なりうる——保留は状態、探索はその間の処理、として分けているが、未検証）。両方を満たす＝独立候補／片方を満たさない＝派生（表に残すが別形態と数えない）／保留＝実データ待ち。

**非固定・未証明の明記。** 上の八つは候補であって網羅でなく、独立性・閉包性は未証明である。
