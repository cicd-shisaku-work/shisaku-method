# 区別

本資料の一覧を読むときに落としてはならない、原典が置く三つの区別——

1. **変容コスト≠変容量。** 十年悩んで変わらないことがあり（コスト大・量小）、一瞬の統合で大きく書き換わることがある（コスト小に見えて量大）。コストは過程の負荷、量は結果（予測モデルがどれだけ書き換わったか）。
2. **抵抗≠負荷。** 抵抗は押し返し（否定・慣性）、負荷は処理量。「難しすぎて受け付けない」は高負荷だが抵抗でない（探索の形）。原典の予測6 はこの区別を反証可能にする。
3. **快／痛≠深さ。** 統合は快く、闘いは痛い。どちらも深い層に届く。快いから浅いのでも、痛いから深いのでもない。抵抗が強ければ深い（片側）、抵抗がないことは浅さを意味しない。
