# 軸の候補
<!-- machinery-def: 変容を読む軸の候補 -->

| 軸 | 何を測るか | 読み方 | 原典の対応 |
|---|---|---|---|
| **深さ（縦）** | 変容の距離 | その変容が**判定を動かした境界の量**——一律だった判定が条件付きになった・逆転した量 | 変容量の節「深さの読み方」 |
| **本数（解像度）** | 境界の在庫 | 立っている境界の数。判定を動かしていなければ深さでない | 同（「詳しい」と「深い」の区別） |
| **横（統合）** | 結合の度合い | 個々の変容が互いを包む一段上の構造に結ばれているか（結合則の産物） | 変容量の節・結合則 |
| **帰属（自己への近さ）** | 書き換え対象が自己に近いか | 近いほど否定する量が大きく、抵抗が出やすい。深さとは別 | 構造の節（抵抗の条件）・〔idion-cost-forms.md〕 |
| **対象（何が書き換わったか）** | 書き換わった層の名 | 着眼／判定の値／判定の手続き／自己像／世界解釈／自己規定……（§3） | 変容量の節の層（書き換わる対象） |

**「深さ」の弁別（日常の発話から）。** 人が「深い」と言うのは、相手の一言が自分の一律の判定に境界を立て、その境界で判定が動くとき。細部だけなら「詳しい」、射程だけなら「壮大」、抽象語だけで境界が無ければ「深そう」（偽の深さ——要約すると何も残らない）。深さは境界の**本数**でなく、境界が**判定を動かした量**。境界は言語に限らない（身体が刻む境界がある）。
