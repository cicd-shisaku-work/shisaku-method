# 位置づけ（原典／応用の線）

**帳簿注記（2026-09-07・SHTT v0.2 との整合＝裁定済）:** 原典の未決「層が深さの目盛りか対象か」は**対象**で決着した。深度語彙の正本は SHTT「命題と、変容の定義」の節と補足〔shtt-depth-terms.md〕——「深さ＝判定を動かした境界の量」は、変容深度（書き換わった前提から上る最長のたどりの段数）・変容広さ（動いた判定の本数）・在庫（立ったが動かしていない境界の本数）の三つに割れ、帰属は**自己距離**として深度と別に読む。本資料の §2 表の「深さ」行は旧定義のまま非破壊で残す（読み替え＝深さ→変容深度・本数→変容広さ／在庫・帰属→自己距離）。§6 のフィードバック候補のうち「層は目盛りか対象か」は決着、「受け手側の写像」は SHTT 補足〔shtt-depth-terms.md〕の共鳴深度（受け手が辿った量）が引き取った。

原典は、強度の二成分（縦＝深さ・横＝結合）、深さの読み方（判定を動かした境界の量）、深さと抵抗が同じ量でないこと、核が層をなすこと（着眼・判定軸・自己像・世界解釈は目安であって区切りでない）、までを置く。**層が深さの目盛りか、それとも「何が書き換わったか」の対象の一覧か**は、原典の未決であり、上位理論（SHTT の「深さ」）との整合の中で裁定される。本資料はその裁定を先取りせず、**軸の候補集合と、その独立性を検査する手続き**を置く地図である。

判別子は一問——**その項目は、媒体・受け手・文脈を変えても不変か。** 軸の存在と区別は原典、軸の候補と対象の一覧は本資料、どの軸を採るか・重みは実装のプロファイル。
