# 弁別子
<!-- machinery-def: IDION の弁別子 -->

本節は、各節の弁別子（その節の規則を一問に畳んだもの）を一か所に集めた写しである。直すときは、各節を直す。

- **IDION か**——その理解・体験・観測・論旨・合成に、本人の予測モデルが書き換えを迫られ、変容コストを経た経緯が辿れるか（移せるものは IDION でない——非移転は必要条件）（{{title:subject/axiom}}・{{title:subject/extension}}）。
- **深いか**——その変容は、意識して呼び出さなくても行動（内的・外的）に出るか。書き換わった前提から、どれだけ上流までたどれるか（変容深度）。抵抗があったなら、どれだけ大きかったか（片側・{{title:subject/strength}}・{{title:subject/judgment-asymmetry}}）。
- **変容量**——どれだけ変容したか（深さ＝変容の距離＋結合による統合度）。変容コストの量ではない。一次判定は本人（{{title:subject/strength}}・{{title:subject/judgment-asymmetry}}）。
- **結合か加算か**——A・B のどちらにも該当しない接触で、C に沿った行動が出るか（{{sec:subject/strength/combination-rule}}）。
- **偽装か**——自分の IDION に無いものを、自分のものとして表現しているか（一次判定は本人）。受け手は、深さを自分のものとして表現している表現に限り、要約テストで実体の空を暴く（{{title:subject/judgment-asymmetry}}・{{title:subject/disguise}}）。知らずに起きた不一致は偽装でなく表現化の失敗。
- **品格**——誠実（偽装しない）＋視線（表現化の失敗を放置しない・見下さない）。対象別に読む（{{sec:subject/dignity}}）。
