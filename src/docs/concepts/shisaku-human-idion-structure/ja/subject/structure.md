# 構造
<!-- machinery-def: IDION 形成の過程 -->
<!-- machinery-def: 書き換え抵抗の向き -->
<!-- machinery-def: 闘いの出口 -->

IDION を形作る過程は、並列の要素でなく、**一本の時間軸の局面**である。過程の正本（両端共通の八段＝接触→気づき→再演段→照合段→承認段→書き換え段→定常化段→折り返し段・六つの区別・照合段の四枡・承認段の出口四つ）は上位理論 SHTT「命題と、変容の定義」の節と補足〔shtt-process-stages.md〕に置く。本節はその**入口側（表現者側）の姿**であり、局面の列は同じ過程を表現者側の語で述べたものである——

> **接触 → 既存の核との照合 → 説明・吸収できない（違和感） → 駆動が「無視できない」と鳴る → 書き換え要求 → 変容コスト（書き換えが既存の構造を否定する・身体や習慣の慣性があるなら抵抗との闘い／どちらもなければ統合） → 書き換え（＝変容） → 新しい核**

各局面の機構——

- **照合。** 接触（外部刺激＝世界・他者・表現／内部刺激＝内省・想起・夢）は、まず現在の核と照合される。核が接触を濾す——濾す側と形作られる側が同じ核である（{{sec:subject/definition}}）。照合は記憶の総体も参照する。
- **格納か、要求か。** 既存の核で説明・吸収できる接触は、記憶として格納されるだけで、核は書き換わらない。説明できない接触は違和感（予測誤差）を立てる。ただし違和感が立っても、**駆動が鳴らなければ**要求は立たず、未説明の記憶として格納される（後の接触で結合の材料になりうる）。駆動が「これは無視できない」と鳴ったとき、核への書き換え要求が立つ。
- **駆動の層。** 「無視できない」「これでいいのだ」という確信は、核でなく、核の**下**にある駆動（欲求／忌避）の層から鳴る。駆動は言語化以前であり、IDION は駆動より上の、言語化がある程度可能な層である。何を核に残すかを選ぶ機構は、核の外＝駆動にある。確信の強さは、変容の価値や正しさの評価軸にしない——防御的な書き換えも、合理化も、強い確信を伴う。
- **変容コスト——書き換えを成立させる内部の処理。** 書き換え要求が立ってから書き換わるまでに、本人の内部で処理が要る。これが変容コストであり、{{sec:subject/axiom}}の「コスト」の中身である。外形の負担（時間・労力）は接触側の性質であって、変容コストではない。変容コストがどんな形をとるかは、書き換えが既存の構造をどれだけ**否定する**か（自己像・判定・共有していた規範）と、身体・習慣の**慣性**で決まる。否定も慣性もなければ、変容コストは**統合**の形をとる——保留していた違和感が結合して解け、世界の見え方が一気に変わる。否定か慣性があれば、**抵抗との闘い**の形をとる。変容コストの形は、快にも痛にもなる。形態の一覧は補足〔idion-cost-forms.md〕が担う。
- **抵抗との闘い＝変容コストの一形態。** 書き換え要求が既存の構造を否定するとき、既存の核は抵抗する——信じていたものを捨てる恐怖、自己理解の否定、過去の判断が誤っていた可能性、積み上げの組み替え、自分の一部が変わる恐怖、核の喪失＝自己喪失の恐怖。闘いとは、この抵抗と**闘うこと**である——矛盾の苦しみ、悩みの苦しみ、迷いの苦しみ、恐怖の苦しみと、一つずつ反論しながら闘う。これが「痛み・リスク」の中身である。抵抗には向きが二つある——既存の核が要求を押し返す**防衛**と、駆動が向かう先へ既存の核（身体・習慣）が追いつかない**慣性**。どちらも自分の中の重力である。
- **闘いの出口は三つ。どれも変容である。** 欲求側が勝てば**受容的な書き換え**（「自分にもこの欲望がある」）。忌避側が勝てば**防御的な書き換え**（「この種の接触は脅威だ」——核が排除の方向へ動く。これも変容であり、しばしば深い）。決着がつかなければ**保留**——要求は残存差分として核に残り、後の接触を待つ（{{sec:subject/strength/combination-rule}}）。保留には自覚の有無がある。無自覚の保留は、きっかけや他者の指摘（接触）で自覚のある保留へ変わり、自覚のある保留は後の接触で結合して解ける。書き換えは一撃でなく漸進しうる——抵抗に一つずつ反論が勝ち、部分の受容が全体の受容へ広がる。統合の形をとる書き換えは、この闘いを経ずに受容的な書き換えへ至る——保留の結合そのものが書き換えである。
- **過程は一周で終わらない。** 書き換えの産物は次の接触になる——書き換わった判定や解釈が波及した先（自己像・過去の判断）で、再び照合が起き、要求が立つ。世界の解釈が変わる段では快く、それが「では今までの自分の判断は」と自己像へ届いた段で痛む、という順で同じ変容の中に快と痛が現れる。
- **変容＝残ったもの。** 書き換えの結果が変容であり、IDION の実体である。IDION は変容の側（残ったもの）にあり、変容コストはそこへ至る道である。

**変容は良いものとは限らない。** ここでいう変容は成長でも学習でも肯定的な変化でもなく、**以前と同じではいられなくなった差分**である。「こういうことは痛い」と知ってしまった、「二度としない」「この種の人間は信用しない」「この音を聞くと怖い」——世界についての予測・認識・感覚・行動可能性が変わった差分は、向きを問わずすべて変容であり、IDION を形作る。

この過程は、受け手の側で起きること（予測→外れ→再解釈→着地＝SHKST）と同型である——表現者もまた、接触→違和感→変容コスト→変容の時間軸で自分の核を得る。同じ変容の力学が、入口でも出口でも働く。表現の受け手の反応もまた、表現者への次の接触である——他者との相互作用で核が更新され続ける循環になる。

**失敗機構。** 局面を無関係の項目として並べると、それはリストであって体系でなく、生成力を持たない（何が何を生むか言えない）。一本の過程として持てば、「時間を掛けたのに何も変わらない」（格納のみ＝要求が立たなかった）、「変容したように見えるが書き換えの経緯が無い」（借り物＝{{sec:subject/axiom}}）、「拒んだのに変わっている」（防御的な書き換え）、「十年後に突然変わる」（保留の結合）、「闘っていないのに世界が変わった」（統合）が、同じ図で見える。闘いを書き換えの必要条件にすると、統合による変容を取りこぼす。駆動を核の内に置くと、「説明できない接触を、説明できないはずの核が確からしいと判定する」という矛盾に落ちる——判定器は核の下にある。
