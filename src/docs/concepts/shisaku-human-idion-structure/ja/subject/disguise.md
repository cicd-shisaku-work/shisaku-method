# 偽装
<!-- machinery-def: 表現の不一致の源 -->
<!-- machinery-def: IDION 表現の層 -->

偽装は「IDION のない技巧」ではない。**偽装＝自分の IDION に無いものを、自分の IDION から出たものとして表現すること**である。照合先は本人の IDION であり、判定の対象は表現の内容でなく、**その表現が何を自分のものとして表現しているか**である。

この定義は三つを含んでいる。(1) 不一致——表現したものが本人の IDION に無い。(2) 本人の認識——本人はそれを知っている（不一致の一次判定は本人にしかできない＝{{sec:subject/judgment-asymmetry}}）。(3) 受け手——表現は受け手の内部に「これはこの人の実体から出ている」という状態を再構成させる行為なので（SHEST §7）、受け手をそう受け取らせることは表現の定義に内蔵されており、別の条項を要しない。

**知らずに起きた不一致は偽装でない。** 本人が IDION と照合しないまま、あるいは照合を取りこぼして、IDION に無いものが表現に混じったなら、それは**実体の表現化の失敗**である——自己一致の不全（{{sec:subject/judgment-asymmetry}}）であり、実装側（構成・表層・実装＝SHEST）の問題で、監査で直る。不一致の源は二つある：**表現側**（自分のものでないものを自分のものとして表現する＝偽装・本書）／**実装側**（自分のものが表現に正しく出ない、または自分のものでないものが混じる＝表現化の失敗・SHEST）。受け手には同じ不一致に見えるが、直し方が違う。他者や道具が敷衍した表現（{{sec:subject/extension}}）は、本人が IDION と照合して引き受けるまで、この意味で誰のものでもない——引き受けの主体を欠いたまま「私の考えだ」と表現したとき、偽装が成立しうる。生成の手段（自分で書いたか、道具が書いたか）は本質ではない。

**表現には表現者がいる。** 帯の惹句は出版社の表現、本文の一人称は著者の表現、題は（様式上）本人の表現である。偽装は、**その表現を出した者**に帰属する——帯が偽っても著者の誠実は損なわれず、出版社の偽装である。受け手が勝手に期待したものは、誰も表現していないので偽装の対象にならない。

**表現は層を持つ。** 体験・論旨・情感・技巧（文体）・構成——「自分のものとして表現しているか」は層ごとに問える。どの層を自分のものとして表現していることになるかの既定は、**様式（ジャンル・慣習）が与える**——自伝という様式は体験を自分のものとして表現しており、文体を自分のものとして表現していない（代筆が常態だと知られている）。ゆえに代筆の自伝で文体が本人のものでなくても偽装でなく、「私の文章だ」と文体まで表現すれば偽装になる。層の一覧は補足〔idion-cases.md〕が担う（固定しない）。

**技巧・演技・虚構は偽装でない。** 体験・思想を自分のものとして表現する表現は **IDION と技巧の両輪**を要し、技巧だけで体験を装えば偽装になる。技を表現する表現（エンタテインメント・言葉の芸・技くらべ）は技巧で立つ。その表現者は、深さを自分のものとして表現していないから偽っていない。しかも技を極めること自体に予測モデルの書き換えの経緯があり、技巧にもそれ自身の IDION がある（{{sec:subject/extension}}・{{sec:subject/strength}}「種類を問わない」）。ゆえに技巧を技巧として表現すれば、偽装でなく**別ジャンルの本物**である。演技も同じ——悲しくない者が「悲しい人を演じている」として泣くのは、演技として表現している。偽装になるのは、演技として表現せず「本当に悲しくて泣いている」として表現するときである。**嘘と偽装も別**——事実命題として偽を述べることが偽装なのではなく、事実として真でも「これを心から感じている」と IDION に無い情感を自分のものとして表現すれば偽装であり、逆に虚構（事実として偽）でも虚構として表現していれば偽装でない。斬るのは偽装だけ——技巧を見下す側（IDION 至上）にも、技巧を全否定する側にも落ちず、「深い体験がなければ表現する資格がない」という当為からも表現者を解く。

**偽装は道徳でなく力学で斬る。** 偽装は、受け手の中に「これは深い」という予測を立て、実体が無いからその予測は外れ、受け手には何も返らない（受け手は「読めるが何も起きない」空振りを感じる）。そして偽装の信号は高コストでしか維持できないため（{{sec:subject/judgment-asymmetry}}）、時間がたつほど露見しやすい。斬るべき理由は罪でなく、この力学——**予測を立てて裏切り、何も返さず、遅れて露見しやすい**——にある。ゆえに「偽装」は、道徳の語でなく構造の語として用いる。贋金の類の比喩は採らない——貨幣語であり（{{sec:subject/definition}}で退けた枠）、かつ犯罪語ゆえ、道徳で切らないという本節の要求を語自身が裏切る。

**失敗機構。** 「IDION なき技巧＝偽装」の粗い定義は、正直な技くらべを誤爆し、逆エリート主義に落ちる。不一致を一律に偽装と呼ぶと、知らずに起きた表現化の失敗（他者・道具との協業で構造的に起きる）まで偽装になり、直せる不一致と直すべきでない偽装の区別が消える。表現の主体を一つに畳むと、第三者の表現（帯）を著者の偽装に数え、作品の品格と表現者の品格が割れて見える。層を無視すると、代筆の文体を偽装に数える。
