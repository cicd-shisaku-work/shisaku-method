# 輪郭の定義度

強度を像で言えば、**輪郭の定義度**である。(a) 深さは輪郭の鋭さ（どこまで深く刻まれたか）、(b) 統合は輪郭の結ばれ方（個々の変容が、互いを包む一段上の構造に結ばれているか＝{{sec:subject/strength/combination-rule}}の産物）。輪郭は基準（平均）との差でなく、それ自体の結ばれ方で定まる——{{sec:subject/definition}}の「基準を持たない」は、ここで強度の定義と噛み合う。輪郭を「一つの形に締まっていること（無矛盾）」と読まない——矛盾を包む構造も輪郭である（{{sec:subject/strength/combination-rule}}）。

変容は種類を問わない——人格の変容も、能力（技巧）の変容も、同じ規則で IDION を形作る。技を極めた鍛錬の変容は、体験の変容と同じ資格で IDION である。

**失敗機構。** (1) 強度を「かけた時間・労力」や「経験の数」に還元すると、量と変容は非比例ゆえ、十年の凡作が強い IDION に見える——**記憶の総体は IDION でない**。思い出せる記憶がいくら増えても、それらが結合せず並存するだけなら IDION はほとんど変わらず、逆に一つの接触が判定の層まで届けば IDION は大きく変わる（経験量≠IDION 量）。IDION は記憶の総体から、変容を通じて選択・圧縮・結合されたものである。(2) 強度を「受け手のモデルがどれだけ書き換わったか」で測ると、それは出口（成果・実体）側の量であり、入口の IDION と偽装の判定（{{sec:subject/disguise}}）の軸が重なって、二つを分けた意味が消える。強度は負った側（本人の変容）で測る。(3) 累積の結合則を比喩（点→線→面）のまま置くと、装飾で終わり、「なぜ人は一冊では変わらず十年後に突然変わるか」の説明力を逃す。規則（条件・契機・産物・弁別子）として持つ。(4) 結合則を本書の外に別建てすると、同じ規則が二箇所で育って齟齬を生む（二重定義）。規則の正本は本節に置き、他は参照する。
