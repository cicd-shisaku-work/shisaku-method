# 累積の結合則
<!-- machinery-def: 累積の結合則 -->

変容の累積は、加算でない。変容 A と変容 B が結びつくとき、しばしば A＋B でなく**別の構造 C** が立ち上がる（結合・再編成）。SHTT §1 はこれを「累積」として系全体の性質に置く。本節はその**結合の規則**——どの差分が、どんな契機で結合し、いつ C が立ち上がるか——を置く。規則は表現者の IDION の育ちとして述べるが、変容が両端で同じ力学である以上、受け手の側の累積にも同じ規則が当たる。

- **結合の条件（何が結びつくか）**——二つの残存差分が、本人の**同じ前提**に触れているとき、結合しうる（対象は問わない——仕事の失注と技術の障害は対象が違うが、「単純化は壊す」という同じ前提に触れて結合する）。触れる前提が無関係なら、並存はしても結合しない。
- **契機（いつ結びつくか）**——結合は、新たな接触（体験・表現・別の変容）が既存の残存差分と予測誤差を起こしたときに誘発される。ゆえに結合は接触の直後に限らず、十年後の別の接触が契機になる（一冊の本が「なんだか面白かった」で終わり、十年後の経験と再結合して「あれはそういうことだったのか」になる）。残存差分は、未来の結合の材料として、期限なく待つ。
- **産物（C が立ち上がったか）**——結合の産物 C は、A と B の両方を包む一段上の構造であり、A・B のどちらからも単独では出ない予測（空白が見える・次が導ける＝生成力）を出す。
- **弁別子（結合か加算か）**——**A・B のどちらにも該当しない接触で、C に沿った行動（外的・内的）が出るなら結合。C に沿った行動が A・B に該当する接触でしか出ないなら加算。** C は A・B の外の予測を出す、をその行動で読む（{{sec:subject/judgment-asymmetry}}・変容は行動に反映される）。本人には一次判定の道具であり、外部からは信号としての二次推定になる。

**矛盾は弱さでない。** 深い変容が二つ、互いに矛盾したまま残っている核（「人は信用できる」と「人は裏切る」の両方が行動に出る）は、**深い保留**（{{sec:subject/structure}}）を抱えた核であって、弱い核ではない。矛盾は未結合の深い材料であり、両者を包む C（「信用と裏切りの両方を成り立たせる構造」）が立てば統合される。立つ前も、矛盾は空白を作り、そこから次が導ける。弱いのは矛盾を持つことでなく、矛盾を浅く放置してどちらも行動に出ないことである。

点→線→面は、この結合が繰り返された像である——点（個別の変容）が同じ層で結合して線になり、線が重なって面（体系＝全体像＋相互関係＋生成力）になる。IDION が面になったとき、空白が見え、新しいものを導ける。それが最も強い IDION である。強度は**動的に育つ**——過去の点が後の接触と結合して、ふいに面になる（熟成）。
