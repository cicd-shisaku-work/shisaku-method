# 外延
<!-- machinery-def: IDION の外延 -->

IDION の外延は、生きた実体験に限らない。三つの水準を分ける——**IDION を形作る接触**、**IDION そのもの（核）**、**IDION の表現化**。

- **体験・観測**——生きた・見た・失敗した・観測した。核を形作る接触であり、そこで起きた変容が IDION になる。
- **論旨**——その人が自分の観測と核で立てた考えの筋。論旨は **IDION の部分または全体の言語化**である。核は言語化できる部分と、できない部分（手・身体・判定の癖）を含むので、論旨は核の射影であり、100% は一致しない。構造や設計を論じる局面では、本人が対話や思考で立てた論旨が、核の主な表現化になる。ゆえに、本人の論旨を他者や道具が敷衍し・articulate することは、IDION を損なわない（本人が核を握り、他者が演奏する分業）——ただし無条件ではない。演奏された表現が誰のものになるかの条件は{{sec:subject/disguise}}が定める。言語化は読み出しではなく折り返す——言語化する行為そのものが核を更新する接触になる（{{sec:subject/structure}}・自己一致）。
- **合成**——未経験を、自分の体験を素材に内的にシミュレーションして作ったもの（フィクションで、作者が経験していない喪失を、自分の別の喪失から合成する）。その源泉が本人の変容に接地している限り、合成も IDION の表現化である。

弁別子は一問——**その論旨・合成は、本人の変容（体験・観測・思考の経緯）に辿れるか（provenance）。** 辿れる＝IDION から出たもの。辿れない＝本人が持たない論旨・情感の発明（{{sec:subject/disguise}}）。

**失敗機構。** 外延を逐語（本人が書いた実物）に狭めると、構造や概念を論じる表現が原理的に書けなくなる。外延を緩めすぎると、道具や他者が本人の持たない論旨を発明して本人の観測として出す。両方の綻びを、同じ一問（辿れるか）が塞ぐ。論旨を IDION そのものと同一視すると、移せる文章を核と取り違え（{{sec:subject/axiom}}・非移転）、再ドリフト（3）逐語のみの読みへ戻る。

**固定しない。** 外延の種類分け（体験・知識・技巧・構成……）は「どこで核が書き換えを迫られたか」の**場所の名**であって、歯止めではない（歯止めは{{sec:subject/axiom}}）。種類の一覧と例は、補足〔idion-cases.md〕が担う。
