# 判定の非対称

本人の変容量の**一次判定権は本人にある**。変容は身体の内で予測モデルが書き換わることであり、外から観測できない。ただし一次判定権は自己申告の無謬性ではない——**本人が深いと言えば深いのではない。本人が深く感じているのであれば、その人にとって深い。しかし、そのクオリアとしての深さを、他者が直接測ることはできない。** 本人が言語化していなくても、内部で大きな変容が起きていればそれは深く、本人が深いと主張しても、予測モデルの書き換えが小さければ深くない。それを読むのも本人であり、手がかりは主張でなく、次の段落の「行動への反映」である——「深く感じている」とは、そこに出ていることを言う。判定権は本人にあるが、判定の対象は申告でなく予測モデルの書き換えである。

**「感じている」とは、言語化できることではない。変容が、意識して呼び出さなくても行動に反映されることである。** 行動には外的行動（身体——顔面をもらった間合いで身体が勝手に引く、二十年練習した手が動く）と内的行動（判断・言語化——考えるとそう判断してしまう、言葉にするとそう出てしまう）がある。弁別子は一問——**その変容は、意識して呼び出さなくても行動（内的・外的）に出るか。** 出るなら深い。言語で「知っている」だけで行動に出ないなら、それは格納であって変容ではない（{{sec:subject/structure}}）。格納された言葉も、呼び出さずに口をついて出ることがある（暗記した文句）。それは格納の再生であって、変容の反映でない。分けるのは、覚えた内容がそのまま当てはまらない新しい接触で、判断や行動が変わって出るかである。ただし外的行動は、抑制・文脈・規範で出ないことがある——出ないことは浅さの証明でない。内的行動（考えるとそう判断してしまう）は抑制しにくく、そちらで読む。本人側の判定信号は**自己一致**（シサク・ヒト変容理論「目標と自己」の節・シサク・ヒト表現構造理論「クオリア欲求の類型」の節の内向きの変容）——出した表現と予測モデルとのずれが、しっくり来るか来ないかとして本人に返る。しっくり来ないものは IDION とずれている。抵抗の大きさ（{{sec:subject/strength}}）も、抵抗があった変容については、本人にとって深さの片側の間接指標になる。経緯は闘いに限らない——統合による変容は、外から辿れる経緯（闘いの跡）を残しにくく、行動への反映と一次性の細部で読む。

**理由は、読み出すのでなく探して当てる。** 本人は、自分の判定がどの予測モデルを通って出たかを、内から読み取れない。「なぜそう判定したのか」と問われて本人が答えるのは、判定の経路を読み出すことではない——手持ちの記憶と言葉から候補を探し、一つずつ当てて、身体に出ている感じと照合することである。探すのを止めるのは、外の正解に合ったときではなく、当てた理由が腑に落ちたとき——自己一致したとき——である。その場で見つからなくても、探すことは終わらない。取り出せなかった理由が、後から出ることがある。ただし、いつ出るかは何も保証しない——「そのうち出る」は、探すのをやめる理由にならない。

判定は各時点の量に対して行う。二十歳で読んだ本が「面白かった」で終わり、三十歳の出来事で「あれはこれを言っていたのか」と以後の見方が変わったなら、二十歳の接触は判定を動かさない**残存**（帰趨の二値のうち変容でない側＝シサク・ヒト変容理論「命題と、変容の定義」の節）として材料のまま残り、三十歳に**新しい深い変容**が結合として起きた（{{sec:subject/strength/combination-rule}}）。深さは遡らない——判定に「後で分かる潜在の深さ」を置くと、本人にも見えない量を本人が判定することになり、一次判定権が成り立たなくなる。

一方、受け手は IDION そのものを観測できないが、**信号の偽装困難さ**を通じて間接に推定できる。二つのコストを分ける——

- **(a) IDION のコスト**——予測モデルの書き換えを成立させた変容コスト・変容。観測不能（本人の領域）。
- **(b) 信号のコスト**——それを表現に出すときの、偽装の困難さ。受け手が読める。

(a) を持つ者だけが低コストで出せる信号（一次性の細部・解像度・結ばれた輪郭）があり、持たざる者は高コストでしか——時間差で綻ぶ形でしか——偽造できない。受け手は、その表現で表現者が自分のものとして差し出したものに対して実体が空でないかを問う（要約テスト＝要約しても残るものがあるか）ことで、偽装を検出する。要約して残るのは境界——一律を条件付きにし、判定を動かすもの——である（{{sec:subject/strength}}「深さの読み方」と同じ物差し）。抽象語だけで境界を持たない表現は、深そうに見えて要約すると何も残らない。**要約テストは、その表現が深さ（体験・論旨）を自分のものとして表現している場合にだけ当てる**——技を表現する表現（言葉の芸・技くらべ）に当てれば空になるのは当然で、偽装ではない（{{sec:subject/disguise}}）。適用条件を外すと、技巧の表現を誤爆して、{{sec:subject/disguise}}が退けた逆エリート主義がこの道具から再侵入する。

判定の非対称は、偽装（{{sec:subject/disguise}}）にも及ぶ。表現が自分の IDION と一致しているか——本人はそれを知っている（悲しくないのに悲しいと表現するなら、不一致を知っているのは本人である）。ゆえに**偽装の一次判定も本人にしかできず**、受け手は信号からの推定（二次判定）で検出するにとどまる。

**失敗機構。** 非対称を無視して外から「これは IDION である／ない」と断定すると、本人が一次判定権を持つ領域を代理判断する（平坦化）。逆に一次判定権を「言えば通る」と読むと、自己申告の無謬性に転ぶ。非対称は穴でなく設計——**変容量と一致の一次判定＝本人／偽装の検出＝受け手の道具（二次）**、と分けて運用する。
