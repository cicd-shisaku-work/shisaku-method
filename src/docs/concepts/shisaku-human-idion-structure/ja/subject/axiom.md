# 公理

本書は、IDION であるかを「その人が最初に言ったか（起源・origination）」で弁別しない。知識も感覚も、元をたどればすべて他者と世界から来る。オリジナルな発想は突き詰めれば無い。ゆえに起源で弁別すると、何も IDION でなくなり、概念が崩壊する。

**IDION であることは、経緯に変容コストがあったかで弁別する。** ここでいうコストは、時間・労力・外形の苦労ではない。**接触が既存の予測モデルの書き換えを迫り、本人がその書き換えを成立させるための内部の処理を経たこと**——これを**変容コスト**と呼ぶ（過程の中の位置は{{sec:subject/structure}}）。**変容コストは一つの形をとらない**——闘いも統合もその形態であり、どの形をとるかの条件は{{sec:subject/structure}}が定める。闘いは変容コストの一形態であって全体ではない。変容コストを経て手にしたなら、外から取り入れたものでも IDION になる。書き換えを経て取り入れたものはその人のものと成り、書き換えを迫られずに取り入れたもの——判断を委ねても、結果を受け入れただけでも、内容について自分の判定が動いていないもの——は、その内容としては IDION でない。ただし取り入れたこと自体は、受け入れてよいという判定が鳴って予測モデルが動いた、小さな変容である。

ここで三つを分ける——**IDION の実体＝その人の予測モデルと機構**（変容は、この予測モデルが書き換わることである）／**形成の過程＝書き換えを迫る接触と、その書き換えを成立させる変容コスト**／**外から辿れる弁別信号＝その経緯**。変容コストの量では、変容量は測れない——**変容コスト（過程の負荷）と変容量（予測モデルがどれだけ書き換わったか）は別の量である**。十年悩んで変わらないこともあれば、一瞬の統合で大きく書き換わることもある。IDION であるかの弁別は経緯を辿れるかで行い、どれだけ変容したかは変容量で読む（{{sec:subject/strength}}）。抵抗は変容コストの一形態であって、コストの量そのものではない——負荷が高いことと、書き換え要求が駆動に押し返されること（防衛）は別である。

弁別子は一問——**その理解・体験・観測に、本人の予測モデルが書き換えを迫られ、変容コストを経た経緯が辿れるか。**

**もう一つの弁別子——非移転。** IDION は他者へ移せない（{{sec:subject/definition}}）。ゆえに、**移せるものは IDION でない**——レシピ・知識・文章は移せる。移せないのは、それらを通じて本人が変わったこと（レシピを再現できるようになった手、判定の癖、見えてしまう目）である。固有性は内容の水準でなく、変容の水準に住む。一問——**それは他者へ移せるか。** 移せるなら内容・素材であって、IDION でない。移せないことは IDION であるための必要条件で、十分条件ではない——駆動のように、移せないが IDION の外にあるものもある（{{sec:subject/structure}}）。

**失敗機構。** 起源で弁別すると崩壊する。逆にコストを「かけた時間・労力の量」に置き換えると、十年の凡庸な反復が大きな変容に見える——外形の負担は接触側の性質であって、予測モデルの書き換えとは別のものである。試験のために暗記して忘れた知識は、時間もリスクも負っているが、予測モデルの書き換えを迫られていない——格納であって変容でない（{{sec:subject/structure}}）。弁別（経緯）と変容量を一語「コスト」で兼ねると、この混線が起きる。逆にコストを「闘い」に固定すると、闘いを経ない書き換え（統合）による変容——発見・理解・結合——を取りこぼし、闘った人ほど変容量が大きいという一面的な像に落ちる。
