# 適用範囲と境界
<!-- machinery-def: IDION が固定しない項 -->

- **適用**——表現者の側の、表現に先立つ基体。媒体一般。表現者は個人に限らず、複数主体（合作・集団）でもよい——複数主体の IDION は単純な和でなく、相互作用して単独では無かった構造を生む（{{sec:subject/strength/combination-rule}}と同型）。一次判定権（{{sec:subject/judgment-asymmetry}}）も集合に属し、表現が集合の IDION から出ているかの一致は集合の内部で負う（一人が「自分たちの体験だ」と表現し他が違うと言うなら、集合として不一致）。外部からは一つの表現者として見える。合意の手続きは実装が担う。
- **排除**——特定の媒体・道具・運用にのみ依存する具体（IDION をどう掘るかの手続き、IDION の有無をどう検査するかの手順、強度の尺度値）は、本書でなく応用の層・実装のプロファイルに属す。
- **固定しない（補足が担う）**——変容の種類の一覧（{{sec:subject/extension}}）、変容コストの形態と抵抗の内訳（{{sec:subject/structure}}・〔idion-cost-forms.md〕）、核の層と軸の候補（{{sec:subject/strength}}・〔idion-axes-map.md〕）、表現の層の一覧（{{sec:subject/disguise}}）、対象別の品格の割れ方（{{sec:subject/dignity}}）。いずれも候補であって網羅でなく、独立性・閉包性は未証明である。具体事例に弁別子を当てた記録と、本書の圧縮が具体で割れたときに分離を検出する手続きは、補足〔idion-cases.md〕が担う。本書の構造を工学のシステムに写して空きを検査する道具は、補足〔idion-system-isomorphism.md〕が担う——同型は検査道具であって、本書の語ではない。
- **framing と operational の区別**——本書の多くは、表現者の核をどこで見るべきかを指定する枠組み（framing）である。反証可能な脚は{{sec:document/falsification}}に切り出してある。
