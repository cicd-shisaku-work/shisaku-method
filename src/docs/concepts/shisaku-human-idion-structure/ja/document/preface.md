# 序

本書の理論名・略号は候補の列挙であり、裁定は提唱者が行う（{{title:document/naming}}の節）。

これは、**表現者の側に立つ、変容の入口の理論**である。ヒトが表現によって他者と自己を変容させる系（SHTT）は、四つの成分——軌跡（SHTST）・表現（SHEST）・距離（SHDST）・共鳴（SHKST）——で**出口側**（受け手の変容の 目標→実装→制約→観測）を担う。本書はその**入口側**——表現が湧き出す基体、すなわち**表現者自身の変容の集合が形作った固有の核＝IDION**——を担う。同じ「変容」が、入口（表現者がどう変容してきたか）と出口（受け手がどう変容するか）の両端に立つ。本書は入口端の構造である。

「シサク・ヒト」の接頭は境界の宣言——前提優位が万物に及ぶのに対し、本書はヒト種へ降りた系である（身体・記憶・痛み・可塑性に依存する）。媒体は一般——文章に限らず、料理人・格闘家・教師・設計者、内部の何かを外へ差し出すあらゆる表現者に、IDION はある。

本書は**仮説であり、設計のための公理系**である。検証された科学的命題ではない。有効性は下流（この理論に沿って作られた表現が受け手にどう残るか）にしかない。本書は前提優位・SHTT と同じく**命令でなく機構で書かれ**、**設計と監査のための文書であって、生成の現場へ添付されない**。

本書をどの物差しで読むか（仮説としての性格・値打ちの所在と反証可能な脚〔{{sec:document/falsification}}〕の位置・生成の現場へ添付しない理由と衣／content の判別）は、shisaku-method README「これらをどう読むか（仮説としての性格）」の七前提と、〔authoring-policy.md〕「原典の値打ちの物差しと反証可能な脚の位置」に従う。

本書は原典（一般理論）である。原典が置くのは、軸の存在・区別・「固定しない」の宣言・弁別規則までであり、中身のリスト（変容の種類の一覧・変容コストの形態の一覧・痛みやリスクの事例集・核の層と軸の候補・強度の尺度値）は置かない——それらは応用層の補足——具体事例集と分離検出〔idion-cases.md〕・変容コストの形態の地図〔idion-cost-forms.md〕・層と軸の地図〔idion-axes-map.md〕・システムとの同型（設計の検査道具）〔idion-system-isomorphism.md〕——と、実装のプロファイルが担う。資料の置き場の統治は〔authoring-policy.md〕に従う。
