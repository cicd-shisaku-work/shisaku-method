# 未決

- **受容と合理化。** 書き換えの出口を「受容」「合理化」と呼び分けるのは、内部では同じ過程（駆動との整合を取る方向への予測モデルの再構成）に、何が書き換わったか（自己像／判定軸／世界認識／行動原理）と、観測者（本人／外部）によって別の名を付けたものである可能性がある。「受容≠合理化」と固定しない。何が書き換わったかの軸で変容・受容・合理化を再整理する射程は、変容の定義（SHTT §1）に触れるため上位理論側で扱う。
- **偽装の像語。** 原理用語は「偽装」で足りる。像語（メッキ・張りぼて等）は要らないかもしれない。
- **{{sec:subject/strength/combination-rule}}。** 条件・契機・産物・弁別子は定式化した仮説であり、実測を経ていない。「C に沿った行動」をどう観測するかの手続きは未定（補足・実装が担う）。
- **駆動と IDION の弁別手続き。** 「譲れない」という確信が、過去の変容が形作った予測モデルから来るのか、生得の欲求・防衛反応・社会的学習・現在の感情から来るのかを切り分ける手続きは未定。駆動を IDION の下に置くモデル自体をどう検査するかも同じ。固定しない。
- **IDION の層は目盛りか対象か。** {{sec:subject/strength}}の層（着眼・判定軸・自己像・世界解釈）は、深さの目盛りでなく「何が書き換わったか」の対象の一覧であり、深さ（判定を動かした境界の量）はどの対象にも当たる別軸である可能性がある。対象の一覧と軸の候補は補足〔idion-axes-map.md〕に置く。**決着（SHTT v0.2 との整合）：層は対象である。** 深さは変容深度（たどりの長さ）として層と別軸で読み、対象の自己への近さは自己距離（帰属）として持つ（SHTT「命題と、変容の定義」の節・〔shtt-depth-terms.md〕）。{{sec:subject/strength}}の層の記述は、v0.3 で対象の語に書き直した。
- **誠実と視線の合成規則**——二軸・対象別まで。
- **補足（応用層の地図）の拡充**——{{sec:application/scope}}「固定しない」の各項（事例集〔idion-cases.md〕は v0.1 あり）。
