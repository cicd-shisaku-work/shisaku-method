# 命名（候補の列挙・裁定は提唱者）

SHTT の略号規則（上位＝SHTT／成分＝SH＋頭字＋ST）を IDION に機械適用すると `SHIST` になるが、英語の卑語に近接し、IDION の命名で剥がした「輸入された含意」を略号で再侵入させる。ゆえに既定候補にしない。候補——

- **A. 略号を作らず、IDION を把手にする。** 理論名＝シサク・ヒト IDION 構造理論（Shisaku Human IDION-Structure Theory）、参照は「IDION」。根拠：略号の役目（像を持たない識別把手）は IDION 自身が既に果たしている。
- **B. 略号を IDION 込みで綴る。** 例：`SH-IDION-ST`。姉妹との型を保つが、冗長。
- **C. 理論名から「ヒト」を落とす。** シサク・IDION 構造理論（Shisaku IDION-Structure Theory）。定義がヒト種普遍を含むため「ヒト」は冗長という読み。姉妹の型（シサク・ヒト〇〇構造理論）からは外れる。
- **D. 「構造理論」でなく「理論」。** 入口の基体は一側面の構造でなく主体そのものだという読み（SHTT が「構造」を持たないのと同じ理由）。ただし本書は主体の全体でなく核の構造を扱うため、私見では「構造」が据わる。

なお SHTT 序の略号規則の改訂（IDION を含めた規則の記述）は、SHTT 側の整合作業で行う。本書は候補を列挙するにとどめる。
