# 接地

本書の各面を**照らす**既知の学説を、傍証として挙げる。向きに注意——学説が IDION を導くのでなく、IDION の各面を学説が照らす。各脚は削除テストに耐える（消すと、その面の説明の一部が薄くなる）が、**本文の論拠の主柱ではない**——本書の主柱は、{{title:subject/axiom}}・{{title:subject/extension}}・{{title:subject/structure}}・{{title:subject/strength}}・{{title:subject/judgment-asymmetry}}・{{title:subject/disguise}}・{{title:subject/dignity}}の機構である。

- **信号の正直さ（コストリー・シグナリング／ハンディキャップ原理）**——{{sec:subject/judgment-asymmetry}}（IDION を持つ者だけが低コストで出せる信号）と、{{sec:subject/disguise}}の露見（偽装は高コストでしか維持できない）を照らす。
- **変容の物理接地（神経可塑性）**——{{title:subject/structure}}と{{title:subject/strength}}の「変容はゼロにならない」「受け入れただけの借り物は核を書き換えない」を照らす。位置づけは、IDION の更新（変容が核に組み込まれる事象）を生物学的に**実装する主要機構の一つ**であって、変容そのものと同一視しない——変容は機能・情報の水準の概念、神経可塑性はその生物学的実装の水準にある。配給にとどめる——これを論拠の主柱にすると、本書自身が「難解語で権威づける」偽装の型に落ちる（自己矛盾）。
- **変容コストの実装形態**——{{sec:subject/structure}}の変容コスト（内部の処理の負荷）は、複数の水準で実装される——神経可塑性（生物学的実装）・学習（認知的実装）・記憶（保持の機構）・感情（重要度づけの機構）・統合が閾値を超えて一気に顕在化する現象（「分かった」の体験）。これらは変容を実装するのであって、変容ではない。変容コストを「脳の演算量」と同一視しない——測れない量を定義に置くと、本書が計算論・神経科学の理論に落ちる。「演算」は説明の像にとどめる。
- **暗黙知・シミュレーション（心の理論・具身シミュレーション・概念ブレンディング）**——{{sec:subject/extension}}（固有性・合成）を照らす。
- **受け手側の変容（自己拡張）**——{{sec:document/upstream}}の出口端を照らす（本体は四成分）。

**失敗機構。** 学説名を本文の主柱にすると、削除テストで「消しても中身が変わらない」衣になり、本書が{{sec:subject/disguise}}で斬る型を自ら演じる。設計層で接地を持ち、本文は機構で立てる。
