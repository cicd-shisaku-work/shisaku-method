# 上流接続

同じ「変容」が、入口と出口の両端に立つ——

- **入口＝表現者がどれだけ変容してきたか＝変容量**（本書）。
- **出口＝受け手がどれだけ変容するか＝表現の価値**（四成分）。

本書は、シサク・ヒト変容理論のパイプライン（主体→軌跡→表現→距離→共鳴→変容）の**主体の位置に立つ入口成分**であり、四成分の手前で「表現者の IDION がどう形作られ、どれだけ強く、偽装されていないか」を担う。入口側の変容と出口側の変容は同じ変容の力学に属するが、両者の量的・因果的対応は本書では仮定しない——IDION が受け手の変容にどう効くか・効かないか（**向きと条件**）は、本書でなく上位理論のシサク・ヒト変容理論が四成分との整合の中で条項化する。本書はここで、入口端の存在と構造を宣言するにとどめる。

**失敗機構。** 入口（表現者の変容）と出口（受け手の変容）を別概念として扱うと、変容が二つに割れて系の芯がぼやける。同じ変容の両端として持つ。逆に、本書が出口側の条件（受け手に何が起きるか）まで抱え込むと、四成分と二重定義になる。
