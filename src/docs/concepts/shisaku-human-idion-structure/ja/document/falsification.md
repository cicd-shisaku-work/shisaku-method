# 反証条件（この理論に固有の予測）

本書は仮説であり、実証は下流にしかない。接地は傍証であって証明ではない。本書だからこそ立てられる予測を挙げる。

- **予測1（外形の負担は強度を予測しない）**——表現者が負った外形の負担の量（時間・反復・労力）は、**本人の変容量**（意識して呼び出さなくても行動〔内的・外的〕に出るかで読む——{{sec:subject/judgment-asymmetry}}）を予測しない。外形の負担と変容量が単調に比例するなら、第1・4節の「強度は変容量であって外形の負担でない」を棄却する。（変容量は内部状態で直接測れないため、行動への反映——外的行動と、判断・発話に出る内的行動——で読む。受け手に残す深さ〔出口側〕との対応は{{sec:document/upstream}}の留保に従い、本予測の対象にしない。）
- **予測2（結合則）**——累積が単純な加算で説明でき、別構造 C の創発（A・B のどちらにも該当しない接触で、C に沿った行動が出る）が観測されないなら、{{sec:subject/strength/combination-rule}}の結合則を棄却する。
- **予測3（契機）**——結合は、既存の残存差分と予測誤差を起こす新たな接触に誘発される。接触なしに（時間経過のみで）結合が観測されるなら、契機条項を棄却する。
- **予測4（判定非対称）**——受け手は、IDION の有無を直接でなく信号の偽装困難さで推定する。IDION の有無を、信号を経ずに受け手が判定できる事例が再現するなら、{{sec:subject/judgment-asymmetry}}を棄却する。
- **予測5（偽装の露見）**——自分の IDION に無いものを自分のものとして表現した表現は、そうでない表現より、時間差で受け手の評価が反転しやすい。反転が観測されないなら、{{sec:subject/disguise}}の力学を棄却する。
- **予測6（抵抗の条件）**——抵抗は、書き換えが既存の判定・自己像・共有していた規範を否定するとき、または身体・習慣の慣性があるときに立つ。いずれも伴わない書き換え要求で強い抵抗が再現するなら、{{sec:subject/structure}}の抵抗の条件を棄却する。（「難しすぎて受け付けない」は負荷であって抵抗でない——反例にならない。）
