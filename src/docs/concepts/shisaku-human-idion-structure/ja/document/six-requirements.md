# 本書の六要件
<!-- machinery-def: IDION 原典の六要件 -->

本節は、原典の六つの枡が、本書のどこで答えられているかを指す。本文に答えの無い枡だけを、ここで埋める。読者は二種——著者の未来の自分・別のセッションと、他者（一般読者）である。

- **意味**——{{title:document/preface}}の節（表現者の側に立つ入口の理論であり、出口側の四成分とどう分かれるか）と、{{sec:subject/definition}}。
- **用法条件**——{{title:document/preface}}の節（設計と監査のための文書であり、生成の現場へ添付しない）と、{{sec:application/scope}}。
- **根拠**——学説の側は{{sec:document/novelty}}と{{sec:document/grounding}}。経験の側はここで埋める——IDION を単語のまま運用すると、局面ごとに狭い読み（貨幣・体験の深さのみ・逐語のみ）へドリフトし、同根の綻び（構造を論じる表現が書けない・技くらべを誤爆する・品格が深度一元化する）が各所で再発した。一つの構造に締めれば、一か所の較正が全体に伝わる。
- **目的**——ここで埋める。ドリフトを止め、SHTT の入口端に正本を置く。下流の実装は本書を引用参照し、再ホストしない。
- **目標**——ここで埋める。著者の未来の自分・別のセッションが、再導出なしに、IDION を「接触によって変容するその人の予測モデルと、それを用いて認知し、判定する機構」として、有無を「予測モデルの書き換えを成立させた変容コストの経緯が辿れるか／移せないものか」で、変容量を「深さ＝変容の距離＋結合・変容コストとは別」で、深さを「意識せず行動に出るか・変容深度・抵抗があればその大きさ（片側）」で、偽装を「IDION に無いものを自分のものとして表現しているか」で、品格を「誠実＋視線」で、一貫して判定できる。他者（一般読者）が、IDION が何かを自分の口で言い、自分や他人の表現に当てられる——どこがその人の変容から出ていて、どこが出ていないかを見分け、なぜ変われないのか・なぜ変わったのかを自分の手で説明できる。
- **効果と失敗機構**——各節の「失敗機構」と、{{sec:document/falsification}}。
