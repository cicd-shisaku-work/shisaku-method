# 改修は暫定対応であり、恒久対応ではない

ここまでの関係から、一つの帰結が論理的に出る。

仕組みを改修すること——設計を直すこと——は、それを運用する各人の前提が変わらない限り、振る舞いを上界の内側で動かすにとどまる。同じ前提の集合は、新しい設計の上で、同じ向きに判断を出し、同じ障害を、形を変えて再発させる。ゆえに改修は、**暫定対応**である。

暫定対応は、要る。出血は止めなければならないし、明らかな欠陥は直さなければならない。本書は、仕組みの改修に値打ちが無いとは言わない。言うのは、それが恒久対応ではない、ということだけである。

**恒久対応**は、上界そのものを動かすこと——各人が己の手綱を握れる状態を、作ること——にしかない。前提を点検し、更新できる各人が増えれば、同じ設計の上で、振る舞いが変わる。そして、その各人の集合が、次の設計を作る。

二つは、優劣ではなく、時間軸の違いである。暫定対応は今日の障害に効き、恒久対応は次の障害の起きる場所に効く。どちらか一方では足りない。ただ、恒久対応の無い暫定対応は、同じ場所で繰り返される。
