# SHEST 補足資料 ― 媒体の四層マップと受容系全表
## Supplementary: Media Four-Layer Map & Reception-System Table

**関連：シサク・ヒト表現構造理論（SHEST）／シサク・ヒト共鳴構造理論（SHKST）／シサク・ヒト距離構造理論（SHDST）**

---

## この文書は何か

これは理論ではなく、**シサク・ヒト表現構造理論（SHEST）の補足資料**である。SHEST は媒体を「表現者の内部状態を、受け手側の状態変化へ変換する経路」と定義する。本資料は、その**媒体の射程**を四つの層に整理し、多様な媒体（文章から料理・格闘技・建築・対人まで）が受け手側の**有限に近い受容系**へ収束することを、一枚の全表で示す。SHEST（表現者側）・SHKST（受け手側の共鳴・変容）・SHDST（両者の距離）を橋渡しする、三理論の接続面の参考仕様である。

暫定版であり、更新を前提とする。閉包性（受容系がこの数で本当に閉じるか）はまだ証明されていない。

---

## 0. 定義・成立条件・境界

- **媒体（SHEST）＝表現者の内部状態を、受け手側の状態変化へ変換する経路。** 記号・物質に限らない。媒体は「物」でなく、**表現者が内部状態を外化する際に操作できる自由度**に近い。
- **表現の成立条件（欲求に由来すること）:** 表現の成立とは、表現者が内部の何かを外部へ差し出そうとする**欲求（意識・無意識を問わない）に由来して媒体を起こすこと**であり、その出力が、受け手（自己を含む）の内部状態変化へ意味的・経験的な経路として（原理上）辿れる状態を作ることである。意図してこそ表現だが、その意図は意識化されていなくてよい（無自覚・無意識でも、背後に欲求があれば表現）。由来するのは表現行為の成立であって、結果として生じた受け手の変容までが表現者の欲求に由来する必要はない。ここから境界が引かれる。
  - **射程外＝純物理因果・強制力**（打撃の物理的ダメージそのもの、薬物の直接作用、拘束）。前提・共鳴・擬似共有を経ない。例：格闘技は「相手や観客の内部状態——恐怖・予測・理解・美——を動かす」限りで表現であり、純粋な物理的破壊の部分は表現でない。
  - **偶然・自然は表現でない（ただし枠づける欲求は表現）:** 欲求に由来しない状態変化（自然物・夕日・偶然のしみ）は、内部状態を外化する主体（表現者）の欲求が無いので、SHEST の媒体ではない（受け手側で鳴る現象＝送り手なき共鳴としては、SHKST が扱える）。ただし、偶然を選び・枠づける欲求があれば、その枠づけは表現である（偶然そのものは表現でないが、偶然を用いる行為は表現）。

## 1. 四層モデル

```
基体 →[構成操作]→ 受容系 →[距離が同調を規定]→ 変化層（残存＝変容）
```

役割分担——**SHEST＝基体＋構成操作（表現者側）／ SHDST＝距離／ SHKST＝変化層・深度**。受容系は、その界面である。

### Layer 1 ― 基体（表現者が成形する材料）
言語（記号列）／音／像（静止・動）／身体・運動／物質（味・香・触・形）／空間。

——**「関係」は基体に置かない。** 対人の相互行為（対話・教育・営業・ケア）は、上記の基体を**応答としてライブに同時進行させるモード**であり、「関係・信頼・地位」そのものは受け手側の**距離軸（関係距離＝SHDST）**および変化層に属す。つまり関係は、成形する材料でなく、相互作用の場と距離である。

### Layer 2 ― 構成操作（基体をどう組織したか）
配置・レイアウト／順序・シークエンス／強弱・アクセント／反復・リフレイン／対比・コントラスト／省略・不在（余白・沈黙・引き算）／変化・変調／同期・遅延・時間配置／ルール・状態遷移／相互作用・応答。
——「存在／不在」は媒体の分類でなく、この層の操作パラメータである（沈黙は音の一種ではなく、音への引き算）。対人相互行為の「応答」も、この層の操作である。

### Layer 3 ― 受容系（受け手の受容経路）
入力器官と推論機構は同じものではないので、二つに割る。
- **感覚系（6）**：視覚／聴覚／触覚（圧・温・質感）／味覚／嗅覚／固有感覚・前庭（運動・平衡）。
- **記号・社会系（2）**：言語・命題（記号を介した推論の経路）／社会的推論（他者の意図・地位・関係の読み）。

感覚系は入力器官、記号・社会系は処理経路である（文章は「視覚→文字認識→言語処理→命題→推論」と進む——言語・命題は入力器官でなく処理経路）。認知・記憶・価値・自己像・世界認識は、受容系でなく、次の変化層に属す。

### Layer 4（別軸）― 距離軸と変化層
- **距離軸（SHDST）＝状態変化を規定するギャップ**（知覚経験・運動・感情・関係・認知・価値・文化・記号・時間/リズム など）。**受容系（入力）とは別**——同じ味覚でも、好み・記憶・文化・知識・共有経験・予測との距離で、生じる状態変化は変わる。
- **変化層（SHKST の深度）**：一本道の順序ではなく、**深度の帯**として読む。
  - 浅い：感覚・運動
  - 中間：感情・記憶・認知
  - 深い：価値・自己像・世界認識
  経路は媒体ごとに違う（音楽→感情→記憶、文章→認知→感情 等）。残存すれば変容、どの帯まで及ぶかが深さ。
  - **注（深度 ≠ 種類）:** ここで挙げた項目（感覚・感情・認知・価値・自己像・世界認識…）は、深度帯への**典型的な対応の例**であって、「項目＝その深度」ではない。同じ対象層でも浅い変容から深い変容までありうる（**深度と種類は直交**）。この帯は「どの種類がどの深度に出やすいか」の傾向の目安である。種類の軸としての対象層は補足〔shtt-object-layers.md〕、深度の階梯は SHKST §4 が担う。

## 2. 基体ごとの射程（例）

- **言語:** 文章／小説／詩／エッセイ／脚本／話術・演説・講演／講義／コピー・標語／命名／ジョーク／説教／手紙／見出し／箴言。
- **音:** 器楽・作曲／歌／声色・朗読・ナレーション／サウンドデザイン／効果音／読経・詠唱／口笛。
- **像:** 絵画／写真／書／イラスト／グラフィック・タイポグラフィ／図解・インフォグラフィック／版画／映像／アニメーション。
- **身体・運動:** ダンス・振付／格闘技・武道／スポーツ・演武／演技／パントマイム／手話／所作・礼法／指揮。
- **物質（味・香・触・形）:** 料理・製菓／調香・香道／工芸・陶芸／プロダクト／服飾・化粧／彫刻／生け花／酒・茶の製造。
- **空間:** 建築／庭園・ランドスケープ／展示・空間演出／インテリア／都市デザイン／茶室／舞台美術。

**対人相互行為（モード）:** 対話／教育・指導／ケア・介護／接客・ホスピタリティ／ファシリテーション／カウンセリング／営業・交渉／リーダーシップ／子育て。——これらは新しい基体でなく、6基体を相互作用（Layer 2）でライブに束ねる場である。営業なら、言語・声・表情（身体）・空間・商品（物質）・沈黙（不在）を使い、関係はそれらを束ねる動的な場になる。

**合成:** 多くの作品は複数基体の合成である——映画＝像＋音＋言語、オペラ＝言語＋音＋像＋身体＋空間、ゲーム＝像＋音＋言語＋ルール、宗教＝ほぼ全域。合成は基体の束＋構成操作として分解できる。

**環境表現（n×n の合成）:** スーパー／ショッピングモール／アミューズメントパーク・テーマパーク／百貨店／商店街／博覧会・展示会／駅・空港・ホテル・カジノなどは、単一の表現者による一作品ではない。**多数の表現者（開発・空間設計・運営・各テナント・演者・スタッフ）× 多数の受け手（来場者）** が、空間を基体に、物質・像・音・身体・ルールを束ね、動線・順序・強弱・相互作用（Layer 2）でライブに同時進行させる——**n×n の環境表現**である。これは合成の大規模版であり、SHTT のカーディナリティ（1×1 → 1×n → n×n）の n×n、および距離の場（SHDST：距離分布・行列）と接続する。分解の視点は二層——(1) 個々の来場者が通る体験の時間経路は、動線・配置・演出として設計される（軌跡＝SHTST の環境版）。(2) 母集団への到達は一様でなく、来場者ごとの距離の分布として散らばる（広さ ≠ 深さ）。ゆえに環境表現の設計は「一人の深い変容」と「多数への浅い到達」を、同じ空間の上で別々に置く多目的設計になる。**それでも分解の単位は変わらない**——基体の束 × 構成操作 × 多主体、であり、受容系は個々の来場者の有限の受容系（§1 Layer 3）へ収束する。

## 3. 基体 → 受容系 全表（典型経路）

**凡例:** ●＝典型的な主経路／○＝典型的な副経路／空欄＝経路が無いのでなく、当該基体の定義上の典型経路として採用していない（実際には環境・接触により他経路も関与しうる）。本表は「典型経路」であって「全可能経路」ではない。

| 基体 ＼ 受容系 | 視覚 | 聴覚 | 触覚 | 味覚 | 嗅覚 | 固有感覚 | 言語命題 | 社会推論 |
|---|:--:|:--:|:--:|:--:|:--:|:--:|:--:|:--:|
| 言語 | ○ | ○ | | | | | ● | ○ |
| 音 | | ● | | | | ○ | | |
| 像 | ● | | | | | | | |
| 身体・運動 | ● | | ○ | | | ● | | ○ |
| 物質（味香触形） | ○ | | ● | ● | ● | | | |
| 空間 | ● | | ○ | | | ○ | | |

音は聴覚が主で、身体同期を伴えば固有感覚に波及する（○）。格闘技（身体）は接触があれば触覚も関与する（○）。建築（空間）は環境により嗅覚・聴覚も関与しうる（表では非採用）。いずれも典型経路の表であり、実際の関与はより広い。

**個別の分解例:**
文章＝言語 ×〔順序・反復・省略〕→〔言語命題・視覚〕／料理＝物質 ×〔対比・順序（コース）〕→〔味覚・嗅覚・触覚・視覚〕／格闘技＝身体運動 ×〔タイミング・フェイント・相互作用〕→〔視覚・固有感覚・（接触時）触覚・社会推論〕／音楽＝音 ×〔反復・同期・遅延〕→〔聴覚・（身体同期時）固有感覚〕／建築＝空間＋物質 ×〔配置・動線〕→〔視覚・固有感覚・触覚〕。

## 4. 全表からの帰結（暫定）

1. **暫定的に全射を確認した。** 本表で定義した8受容系に対して、各受容系へ到達可能な基体が少なくとも一つ存在する——という意味で、基体→受容系の写像は全射である。**世界のあらゆる表現媒体について全射性・閉包性を証明したものではない。** それでも、料理・建築・映画・小説・格闘技・宗教・音楽といった一見まったく異なる媒体が、受け手側では「見る・聞く・触れる・味わう・嗅ぐ・身体で感じる・記号として理解する・他者の意図を読む」という限られた受容系に集約される、という**収束**が見える。
2. **多対多である。** 一つの基体が複数受容系へ分岐する（料理＝触・味・嗅・視／身体＝視・固有感覚・触・社会推論）。単純な関数でなく写像。
3. **文章だけでは足りない。** 味覚・嗅覚・固有感覚は、物質・身体・空間の基体が確かに要求する——これらを入れなければ料理・ダンス・建築・格闘技が落ちる。媒体を文章に留めず広げると受容系は分化・拡張するが、有限の感覚器官の範囲であって、無限には増えない。
4. **受容系 ≠ 距離。** 受容系（入力）は本表の水準で数えられるが、**距離軸（同調を規定するギャップ）はこれと別物**であり、SHDST が扱う。距離軸が有限で閉じるかは、各軸を「予測を出すか（操作可能性）」「他軸で説明できない独立のズレか（非重複）」で検査して判定する——これが次の本丸（SHDST）。

## 5. 未確定（今後の版で）

- **内受容感覚**（心拍・内臓感覚・呼吸）を、感覚系に加えるか、変化層に置くか。ホラーの心拍上昇は視覚・聴覚入力の下流ゆえ変化層寄りだが、呼吸誘導や身体運動による直接介入もありうる。
- **受容系の閉包性**——8で本当に閉じるか（未検証・暫定の全射確認に留まる）。
- **距離軸（SHDST）の全域スキャン**——知識・文化・感情・関係・経験・時間・価値・身体・予測…を並べ、それぞれが本当に独立軸か（操作可能性×非重複）を潰す。受容系の分化（身体→知覚＋運動、時間→リズム）が距離軸の分化で吸収できるか、独立軸の追加を要するかも、そこで判定する。
- 表現の成立条件を、SHEST 本体へ正式条項として繰り上げるか。
